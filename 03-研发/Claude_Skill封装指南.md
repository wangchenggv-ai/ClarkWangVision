## 什么是Skill

可复用的指令包。把工作流程（步骤、模板、判断逻辑、参考资料）封装成文件夹，下次遇到类似任务自动触发、自动按流程走。

## 结构

```
skill-name/
├── SKILL.md          ← 核心：触发条件 + 执行指令
├── scripts/          ← 可选：自动化脚本
├── references/       ← 可选：参考文档
└── assets/           ← 可选：模板素材
```

三层加载：
1. 名字+描述（~100词）→ 永远在上下文，决定是否触发
2. SKILL.md正文（<500行）→ 触发后才读
3. 附属资源 → 按需读取

## 关键技巧

- 描述写得越具体越"贪"越好，宁可过度触发
- SKILL.md用祈使句，直接告诉AI该做什么
- 大参考文档拆到references/，SKILL.md只放流程骨架
- 可以嵌套调用其他skill
