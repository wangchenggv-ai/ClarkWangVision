## 二、需要在UI中手动完成的配置

### 2.1 视图类型转换（2分钟）
飞书API暂不支持创建kanban类型视图，需手动操作：
1. 进入终端客户信息表 → 选择"管道看板"视图
2. 点击视图设置 → 切换为"看板视图" → 分组字段选择"管道阶段"

### 2.2 自动化工作流配置（10-15分钟）
自动化工作流需要通过飞书多维表格UI配置，推荐创建以下规则：

**规则1：新销售上报通知**
- 触发：销售责任上报表 记录被创建时
- 动作：飞书消息通知主管

**规则2：培训审批状态变更通知**
- 触发：培训审批表 审批状态变更时
- 动作：飞书消息通知申请人

**规则3：订单关联自动更新**
- 触发：订单表 记录被创建时
- 动作：查找关联终端客户，更新订单数量

**规则4：每周批量校验**
- 触发：定时任务（每周一凌晨2:00）
- 动作：检测重复记录，标记异常，推送给主管

### 2.3 表单字段配置（5分钟）
进入各表单视图，配置显示字段和必填项：
- 培训申请表单：培训主题(必填)、申请人(必填)、培训日期(必填)、目标医院、预计人数
- 销售上报表单：销售人员(必填)、终端医院(必填)、上报类型(必填)、医生列表、代理商名称
- 会议登记表单：客户姓名(必填)、所属医院(必填)、联系电话、参会状态、来源会议

## 三、系统使用流程

### 3.1 日常销售工作流
1. 销售填写"销售责任上报表单"提交拜访信息
2. 系统自动关联终端客户和医生记录
3. 销售在"管道看板"中拖拽客户卡片更新管道阶段
4. 周五提交周报时查看仪表盘数据

### 3.2 培训/会议流程
1. 申请人填写"培训申请表单"
2. 主管审批通过后自动同步到培训表
3. 会后1周检查出单情况（公式自动计算检查日期）
4. 30天后检查留存和复购

### 3.3 管理层使用
1. 打开"CRM分析仪表盘"查看实时数据
2. 通过管道分布图识别瓶颈阶段
3. 通过销售订单金额图评估团队绩效
4. 通过订单趋势图识别增长机会
