

## 一、核心需求与背景
- CRM结构：代理商信息表（40条）、终端客户信息表（300条，核心枢纽）、医生信息表（500条）。
- 关联关系：代理商↔终端客户、医生↔终端客户。
- 4名销售需上报终端医院和终端医生，预计2026年底数据翻倍。
- 目标：Excel一键导入后，系统**自动完成跨表匹配与关联**，实现零人工维护。

## 二、Excel批量导入完整方案

### 1. Excel文件准备（5分钟）
严格使用以下列标题：
- 上报ID（留空）
- 销售人员
- 终端医院（必须与终端客户信息表一致）
- 医生列表（逗号分隔，例如“李医生,王医生”）
- 代理商名称（可选）
- 上报类型（新增/更新/删除）
- 上报日期（可选）
- 备注（可选）

### 2. 批量导入操作（2分钟）
1. 进入**销售责任上报表**。
2. 点击“导入” → “从Excel导入”。
3. 映射列标题 → 勾选“导入后自动创建新记录”。

### 3. 自动化配置（10-15分钟）

**自动化规则1：导入后立即自动关联（主规则）**
- 触发条件：记录被创建（Excel导入时逐条触发）。
- 动作：
  1. 在终端客户信息表中查找匹配（终端医院名称）。
  2. 条件分支：
     - 若匹配 → 更新“负责销售”、“关联医生”、“关联代理商”。
     - 若不匹配 → 创建新记录，并同步医生信息表。
  3. 更新上报记录状态 + 发送飞书消息。

**自动化规则2：每周批量校验**
- 触发条件：定时任务（每周一凌晨2:00）。
- 动作：检测重复 → 标记异常 → 推送主管。

**辅助公式字段**：
- “医生列表数组” = SPLIT(医生列表, ",")

### 4. 关联效果与后续联动
- 双向关联自动生效（终端客户表、医生信息表实时更新）。
- 自动触发1周出单、30天留存等自动化。
- 仪表盘实时显示各销售负责数据量及增长趋势。

### 5. 实施路线图
1. 今日：准备Excel模板 + 配置规则1。
2. 明日：导入第一批数据 + 查看执行日志。
3. 每周：销售整理Excel批量导入。
4. 权限：销售仅导入权限，其他表只读。

**年底翻倍应对**：自动化支持万级记录，无性能问题。
