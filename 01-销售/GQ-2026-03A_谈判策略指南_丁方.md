## 一、条款分级总览

以下按六大议题逐项列出四个层级：最优方案（争取签）→ 次优方案（可接受）→ 底线方案（勉强签）→ 红线（绝不签）。

### 1. 担保条款（第1条3.2.3 + 第3条）

> 风险等级：**最高**。担保物处置权是甲方对你的终极控制手段。

| 层级    | 条款要点                 | 具体表述 / 操作                                                                        |
| ----- | -------------------- | -------------------------------------------------------------------------------- |
| 🟡 次优 | 仅以乙方股权质押，设上限         | 担保形式限定为丁方持有的乙方股权质押；担保金额上限=借款总额×丁方穿透持股比例；明确排除个人其他资产和连带保证。                         |
| 🟠 底线 | 股权质押+阶段性解除+处置触发加客观标准 | 接受股权质押，但要求：1）借款偿还达50%时解除一半质押；2）第3条处置触发条件增加"经第三方审计确认连续6个月经营性现金流为负"；3）处置前给予90天整改期。 |
| ❌ 红线  | 开放式担保 / 个人连带保证       | **绝不签：** 担保物不明确的空白承诺；个人房产/存款等资产作为担保物；无条件连带保证责任；甲方单方面即可触发处置的条款。                   |

### 2. 竞业条款（第4条）

> 风险等级：**高**。核心策略：不改范围，删重复。

| 层级    | 条款要点             | 具体表述 / 操作                                                                                 |
| ----- | ---------------- | ----------------------------------------------------------------------------------------- |
| ✅ 最优  | 引用已有协议，不新增条款     | 第4条改为一句话："丁方应严格遵守与甲方/丙方已签署的《竞业禁止协议》的相关约定。"理由：避免同一事项双重处罚（竞业违约+担保物处置）。                      |
| 🟡 次优 | 接受重申，但删除担保物处置挂钩  | 保留竞业承诺文字，但删除"甲方有权按照《担保协议》处置丁方的担保物"。违约后果回归劳动法框架（违约金、竞业补偿返还等）。                              |
| 🟠 底线 | 保留全文，但限缩"竞争业务"定义 | 如必须保留全条，争取将"与甲方和/或丙方相竞争的业务"改为"与丙方已注册或已申报的医疗器械产品在中国市场的销售构成直接竞争的业务"。**注意：，仅在最优和次优均被拒绝时使用。** |
| ❌ 红线  | 宽泛竞业+担保物处置+无补偿   | **绝不签：** "任何第三方兼职包括顾问"+违约即处置担保物+无竞业补偿的组合。这等于甲方随时可以用模糊定义触发处置你的股权。                          |

### 3. 知识产权条款（第4条）

> 风险等级：**高**。

| 层级    | 条款要点                  | 具体表述 / 操作                                                                                     |
| ----- | --------------------- | --------------------------------------------------------------------------------------------- |
| ✅ 最优  | IP归属限定为"丙方资源+实际开展的项目" | "丁方任职期间，利用丙方资金、设备、技术资料或人员所完成的、与丙方实际开展的研发项目相关的知识产权成果，归丙方所有。丙方与第三方合作开发的项目，知识产权归属按合作协议另行约定。"（同仁） |
| 🟠 底线 | 接受宽泛IP归属，但加"丙方资源"前提   | "丁方职务行为形成的、利用丙方资源的知识产权归丙方所有。"关键是保住"利用丙方资源"这个定语——个人时间、个人资源做的不算。                                |
| ❌ 红线  | 无条件全归属                | **绝不签：** "丁方在职期间形成的一切知识产权归丙方所有"；"与丙方业务领域相关的知识产权归丙方"；"丁方提出的所有技术方案/构想归丙方"                       |

## 二、签约前必须完成的操作清单

> 以下动作的时间顺序至关重要，必须在签署协议之前全部完成。

1. **要求同步看到《担保协议》：** 不在《担保协议》定稿之前签署本协议。至少要求担保形式、范围、上限、解除条件写进本协议。
2. **确认已有《竞业禁止协议》的具体条款：** 重新审阅已签竞业协议的范围、时限、补偿条款，确保本协议引用时不会无意扩大义务。

## 三、谈判话术要点

> 所有话术的核心原则：动机指向"减少争议""保护公司利益"，不指向个人诉求。

**担保问题：** "我完全理解公司需要风险保障。我建议担保条款和借款协议一起定，这样各方权利义务都清晰，避免将来扯皮。"

**竞业问题：** "竞业我已经签过了，没有任何问题。我的顾虑是同一件事两份协议两种处罚方式，万一将来有争议反而说不清楚。建议统一引用已有协议。"

**IP问题：** "知识产权我完全尊重公司权益，丙方的产品技术当然归丙方。我只是希望条款表述清晰，避免未来产生不必要的争议。"

**出资问题：** "250万没有问题，但拿证时间我控制不了，5个工作日确实太紧。给个合理的缓冲期，对大家都好。"

## 四、最终决策框架

如果甲方在担保、竞业、IP三个核心议题上全部坚持原文不让步，意味着这份协议的目的不是"风险共担"，而是"锁人"。此时需要重新评估：

- 签约的收益（股权、奖励、经营权）是否值得对应的风险敞口
- 甲方的真实意图是合作还是控制

**最坏情况下的退路：** 不签本协议，维持现有劳动关系和竞业协议，保留所有选项的灵活性。代价是放弃乙方股权调整和甲方注资承诺，但也不承担额外的担保义务和加码的竞业限制。
