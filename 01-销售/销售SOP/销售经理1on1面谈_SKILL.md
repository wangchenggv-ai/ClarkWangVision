# 销售经理1-on-1面谈 Skill

**创建日期：** 2026年3月27日  
**触发条件：** 提到1对1、面谈、经理沟通、绩效谈话、sales 1on1

---

## 功能一：会前准备

### 触发方式
用户说"准备X的1对1"、"这周要跟经理谈"。

### 输出：个性化提纲

```markdown
## [经理姓名] 1-on-1 提纲（日期）

### 数据预填
- 本月业绩达成率：___%
- 上月action items完成：___/___
- CRM录入及时性：✅/⚠️/❌

### 必问清单
1. 上月最大的客户突破是什么？具体怎么做到的？
2. 现在最卡你的一件事是什么？
3. 上月你做的最大决定是什么？（决策权检查）
4. 如果我联系不上你一周，你会卡在哪？（自主性检查）

### 条件触发追问
- [如连续未达标] 你觉得根因是什么？你试过什么方法？
- [如季度切换] Q2你的三个核心客户是谁？为什么选他们？
- [如新产品推广期] 成人OK镜/新产品你准备怎么切入？
```

## 功能二：面谈纪要生成

### 触发方式
谈完后口述要点，自动生成纪要。

### CEO判断框架（能力×意愿四象限）

| | 高意愿 | 低意愿 |
|---|--------|--------|
| **高能力** | 授权，给空间 | 激励，找到驱动力 |
| **低能力** | 辅导，给方法示范 | 考虑换人/调岗 |

## CEO情绪管理提醒

1. **面谈前写下预期**：把模糊期望变成明确锚点
2. **先锋标准而非军师标准**：考核执行力和客户冲劲，不考核思维深度
3. **10分钟规则**：发现问题→10分钟内决定行动→继续推进，不在情绪里打转
4. 如果经理写得质量不高：亲自改一份给TA看，让TA照着模仿

## 与其他Skill的协同

- **销售月会Skill**：1对1通常在月会Day 1进行，月会Skill的Step 2调用本Skill生成提纲
- **供应链Skill**：如面谈涉及交付问题，参考供应链数据
