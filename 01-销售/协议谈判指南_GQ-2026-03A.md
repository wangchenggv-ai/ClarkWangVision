# 协议谈判指南（GQ-2026-03A）

**更新日期：** 2026年3月27日

---

## 一、六大议题与四层底线

### 议题1：担保/抵押

| 层级 | 立场 |
|------|------|
| 最优 | 取消个人股权抵押，改用公司资产担保 |
| 可接受 | 抵押范围限定在实际出资额以内 |
| 最低 | 抵押有明确解除条件（如出资完成后自动解除） |
| 红线 | 不签无上限连带担保 |

### 议题2：非竞业

| 层级 | 立场 |
|------|------|
| 最优 | 不新增非竞业条款（已有生效协议） |
| 可接受 | 明确排除"非丙方资源开展的项目" |
| 最低 | 非竞业期限不超过离职后12个月 |
| 红线 | 不接受双重非竞业叠加 |

### 议题3：知识产权

| 层级 | 立场 |
|------|------|
| 最优 | IP归属以"实际使用丙方资源开展的项目"为标准 |
| 可接受 | 第三方合作开发设carve-out条款 |
| 最低 | IP条款不溯及既往 |
| 红线 | 不接受"任职期间所有发明归公司"的宽泛条款 |

### 议题4：出资

| 层级 | 立场 |
|------|------|
| 最优 | 出资时间与工商变更同步 |
| 可接受 | 5个工作日改为10个工作日 |
| 最低 | 出资时间明确且不可单方面提前 |
| 红线 | 不接受"通知后立即出资"的条款 |

### 议题5：奖金/激励

| 层级 | 立场 |
|------|------|
| 最优 | 审计完成后30天内发放 |
| 可接受 | 审计由双方认可的第三方执行 |
| 最低 | 约定审计最迟完成时间 |
| 红线 | 不接受无审计期限约束的条款 |

### 议题6：经营权

| 层级 | 立场 |
|------|------|
| 最优 | 管理层51%投票权+集团限定一票否决权（仅限重大事项） |
| 可接受 | 明确列举一票否决事项清单 |
| 最低 | 日常经营不需要集团审批 |
| 红线 | 不接受集团对日常人事/采购有审批权 |

---

## 二、谈判核心原则

1. 所有诉求包装为"减少争议"而非个人利益
2. **先看担保协议再签主协议** — 绝不分开签
3. **签约前必须完成老花项目正式关闭** — 更新2030年业务计划，移除老花R&D
4. 严格区分丙方资源与个人资源的边界

---

## 三、签约前必须完成的动作

- [ ] 正式关闭丙方老花项目（更新2030 BP，替代增长驱动）
- [ ] 确认担保协议条款
- [ ] 确认IP条款使用"实际开展"标准
- [ ] 确认非竞业不构成双重约束
