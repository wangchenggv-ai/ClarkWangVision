## Session Closing

**Triggers:** When Clark says: "close", "I'm done", "done", "done for now", "new chat", "stop", "close it", "let's stop", "until next time", "save and close", or similar closing phrases → start the closing protocol.

**Closing Protocol:**
1. **Update projects** — update the Projects table above with the current status of each project worked on during this session
2. **Add new terms/context** — if new concepts, facts, or decisions were introduced, add them to the Terms or Context sections
3. **Update folder structure** — if folders were created or moved, update the Folder Structure section
4. **Update memory** — write relevant project details to memory/projects/ if there was significant progress
5. **Provide summary** — confirm to Clark what was saved with a brief summary: "Saved: [what was updated]. You can pick up where you left off in the next session."
