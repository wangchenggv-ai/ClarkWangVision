# Memory 系统使用指南

## 结构

```
~/.claude/projects/C--Users-wangc/memory/
├── MEMORY.md                    ← 索引文件（自动加载）
├── user_*.md                    ← 用户信息
├── feedback_*.md                ← 行为纠正/确认
├── project_*.md                 ← 项目上下文
└── reference_*.md               ← 外部资源指针
```

## 四种 Memory 类型

| 类型 | 写什么 | 示例 |
|------|--------|------|
| **User** | 角色、专业背景、工作习惯 | "CEO，眼科背景，偏好简洁回复" |
| **Feedback** | 纠正过我的做法 | "别派agent扫简单文件"、"回复要简短" |
| **Projects** | 目标、进度、截止日期、关键决策 | "订单系统在华为云，同事测试中" |
| **References** | 外部系统入口 | "飞书Bitable在xxx"、"周会文档在xxx" |

## 怎么用

### 主动告诉我
```
记住：xxx
记住这个路径：xxx
以后别这样做：xxx
```

### 我会自动存
- 对话中发现重要信息时主动写入
- 你纠正我时存 Feedback
- 项目状态变化时更新 Project

## 不该存什么

- 代码逻辑、文件路径 → 读代码库
- git 历史 → `git log`
- 一次性信息 → 当前对话上下文
- CLAUDE.md 已有的内容

## 核心原则

**只存跨对话有用的信息。** 能从代码库直接读到的，不存。
