# 助理电脑环境安装指南 — 高视星供应链系统

> 目标：在助理电脑上装好所有环境，能跑通完整的日常业务闭环
> 预计耗时：30-45分钟
> 前提：Windows 电脑，有管理员权限，能联网

---

## 第一步：安装 Node.js（5分钟）

1. 打开浏览器，访问 https://nodejs.org
2. 下载 **LTS 版本**（当前应该是 22.x），选 Windows Installer (.msi)
3. 双击安装，一路"下一步"即可，**不需要改任何选项**
4. 安装完成后，打开"命令提示符"（Win键 → 搜索 `cmd` → 回车），输入：

```
node --version
```

看到 `v22.x.x` 或 `v18.x.x` 就说明安装成功。

---

## 第二步：拷贝项目文件夹（2分钟）

把 `feishu-setup` 整个文件夹拷贝到助理电脑上。建议放在：

```
C:\feishu-setup
```

路径短、没有中文，避免各种奇怪问题。

**拷贝方式**：U盘、微信文件传输、公司共享盘都行。

> ⚠️ 注意：**不要拷贝 `node_modules` 文件夹**（太大且跨电脑不兼容），下一步会重新安装。

---

## 第三步：安装项目依赖（5分钟）

在命令提示符里执行：

```
cd C:\feishu-setup
npm install
```

等它跑完，看到没有红色 `ERR!` 就行。这一步会自动安装 5 个依赖包：

| 包名 | 用途 |
|------|------|
| undici | 网络请求（调飞书API） |
| xlsx | 读写Excel文件 |
| qrcode | 生成镜片QR码 |
| puppeteer | 浏览器自动化（标签打印等） |
| dotenv | 读取配置文件 |

---

## 第四步：配置 .env 文件（1分钟）

确认 `C:\feishu-setup\.env` 文件存在且内容正确。这个文件已经在项目里了，**不需要助理修改**，但要确认拷贝过来时没有丢失（因为以 `.` 开头的文件在某些系统里是隐藏的）。

**验证方法**：命令提示符里输入：

```
type C:\feishu-setup\.env
```

能看到 `FEISHU_APP_ID=cli_a94d...` 开头的内容就对了。

如果文件不在，从你这边重新拷一份过去。

---

## 第五步：验证系统可用（5分钟）

按顺序跑以下命令，每条都应该正常执行：

```
cd C:\feishu-setup

:: 1. 验证飞书连接 + 12张表都能读取
node full_test.js

:: 2. 启动代理商门户
node agent-portal/server.js
```

第1条：看到 `32/32 pass` 就说明飞书连接和所有表都正常。

第2条：看到 `Server running on port 3210` 后，打开浏览器访问：

```
http://localhost:3210?t=AG-002-zxkmgoryb6nprmv6
```

能看到下单页面就说明门户OK。按 `Ctrl+C` 停止服务器。

---

## 第六步：助理日常操作速查卡

每天工作时，先打开命令提示符，`cd C:\feishu-setup`，然后按需执行：

### 启动门户

```
node agent-portal/server.js
```

浏览器保持开着，别关命令提示符窗口。

### 跑自动化规则（订单验证、库存扣减、超期预警等）

```
node automations.js all
```

### 生成今日镜片标签

```
node print_labels.js
```

输出在 `docs/labels-日期.html`，浏览器打开后 Ctrl+P 打印。

### 同步旧订单表数据

```
node sync_orders.js
```

### 生成仪表盘

```
node dashboard.js
```

输出 `dashboard.html`，浏览器打开查看。

## 常见问题

**Q: `npm install` 报网络错误？**
公司网络可能限制了 npm 访问。换淘宝镜像：
```
npm config set registry https://registry.npmmirror.com
npm install
```

**Q: `node xxx.js` 报 "Cannot find module" 错误？**
说明 `npm install` 没跑成功，重新跑一次。

**Q: 门户启动后浏览器打不开？**
检查是不是端口被占用了，试试换端口：
```
set PORT=8080
node agent-portal/server.js
```
然后访问 `http://localhost:8080`

**Q: 飞书API报权限错误？**
`.env` 文件内容不对或丢失，从 Clark 那里重新拿一份。

**Q: puppeteer 安装很慢或失败？**
puppeteer 需要下载 Chromium（~170MB），网络慢时可能超时。设置跳过下载：
```
set PUPPETEER_SKIP_DOWNLOAD=true
npm install
```
标签打印功能会受限，但下单和自动化不受影响。
