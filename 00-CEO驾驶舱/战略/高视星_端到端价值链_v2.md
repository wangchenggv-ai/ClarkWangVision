## 一、全生命周期端到端（完整版）

```
消费者旅程                          高视星系统覆盖
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[发现期]  家长发现孩子近视         →  公众号/小程序获客，预约门诊
   ↓
[首诊期]  进入签约门诊             →  建档（专病管理系统）
   ↓                                →  AI辅助检查方案推荐（CDSS）
   ↓                                →  配镜方案决策（CDSS：OK镜/离焦镜/阿托品/联合方案）
   ↓
[产品期]  选定产品                 →  下单（订单系统）
   ↓                                →  生产排期（供应链系统）
   ↓                                →  配送+取镜
   ↓
[随访期]  1个月/3个月/6个月复查    →  自动排复查节点（专病管理）
   ↓                                →  异常预警（CDSS：眼轴增速>0.3mm/年触发干预升级）
   ↓                                →  方案调整决策（CDSS）
   ↓                                →  家长端小程序：提醒+数据可视化
   ↓
[复购期]  1-2年换镜               →  自动触发复购提醒
   ↓                                →  方案升级推荐（运营仪表盘）
   ↓                                →  重新走产品+供应链流程
   ↓
[扩散期]  效果好→转介绍            →  转介绍识别+激励（CRM）
   ↓                                →  门诊口碑裂变
   ↓
[毕业期]  18岁+稳定                →  结案评估（CDSS）
                                     →  转成人眼健康管理（第二曲线入口）
                                     →  老花/白内障产品线自然衔接
```

### 比v1多出来的环节

| 新增环节 | 为什么重要 |
|---------|-----------|
| **发现期-获客** | 漏斗最上游，目前门诊靠自然到店，数字化获客是门诊LTV的倍增器 |
| **毕业期-转介** | 近视防控结束不等于客户流失，是成人眼健康的入口 |
| **家长端触达** | 家长是决策者+付费者，单独建触达通道（小程序/公众号），不只是"提醒" |
| **联合方案** | 实际临床经常OK镜+低浓度阿托品联用，CDSS必须支持组合决策 |
| **异常升级路径** | 不只是"管得好"，还要"管不住时怎么升级"，这体现CDSS的临床深度 |

## 三、数据飞轮（升级版）

```
签约门诊（3家→10家→50家）
    ↓
部署系统 → 专病管理 + CDSS
    ↓
采集数据 → 每个患者的检查、配镜、随访、疗效
    ↓
AI训练 → CDSS决策越来越准 → 哪个产品×哪类患者×什么方案最有效
    ↓
效果更好 → 门诊续约率↑ → 更多门诊加入
    ↓
数据量↑ → 训练出行业最强的近视防控AI模型 ← 这是真正的护城河
    ↓
反向赋能供应链 → 基于真实世界数据改进产品设计
    ↓
数据资产变现 → 药企/器械商购买真实世界证据（RWE）
```

**关键飞轮转速指标：**
- 签约门诊数（当前目标：3-5家种子→年底10家）
- 每门诊月活患者数（目标：50-200人/门诊）
- 数据完整率（目标：>80%关键字段完整）
- CDSS推荐采纳率（目标：>60%，越高说明AI越被信任）

## 四、价值在哪里：变现模式分析

### 4.1 五层变现模型

| 层级 | 变现方式 | 估值倍数 | 高视星可行性 |
|------|---------|---------|-------------|
| **L1 产品销售** | 卖镜片/OK镜给门诊 | 8-15x收入 | ✅ 已有，但同质化竞争 |
| **L2 SaaS订阅** | 门诊按年付费使用系统 | 10-20x收入 | ✅ 核心模式，CDSS+专病管理 |
| **L3 效果保障溢价** | "用我的系统+我的产品=效果有保障"，产品溢价15-30% | 15-25x收入 | ✅ 差异化最强 |
| **L4 数据资产** | 真实世界证据(RWE)卖给药企/器械商做临床研究 | 20-30x收入 | ⏳ 2-3年后，数据量够了才能卖 |
| **L5 平台税** | 门诊供应链经过我的系统走，抽佣/导流 | 15-25x收入 | ⏳ 3-5年后，门诊量够大才有 |

### 4.2 现阶段最优变现路径


### 4.3 "效果保障"模式的商业本质

传统模式：门诊买镜片 → 配了就完 → 效果不管 → 家长没信心 → 复购率低

高视星模式：门诊用我的系统+我的产品 → AI管理全程 → 效果可视化 → 家长看到数据 → 信任感→转介绍→复购

**对门诊的价值：**
- 复购率从40%→70%（随访管理不流失）
- 客单价从¥3000→¥4500（方案升级有据可依）
- 转介绍率从10%→25%（效果可视化=口碑素材）

**对高视星的价值：**
- 产品溢价15-30%（不打价格战）
- 锁定门诊供应链（系统绑定=排他性）
- 数据积累→AI变强→效果更好→正循环

## 七、AI时代的加速器

### 7.1 AI对高视星的5个加速点

**① CDSS从规则→模型，3个月变成实时进化**
- 传统CDSS：人工写规则，每条规则要临床验证
- AI加速：用已有数据训练模型，新数据进来模型自动迭代
- 实操：先用RAG+规则引擎打底（2026），逐步过渡到端到端模型（2027）

**② 供应链预测从经验→AI**
- 传统：按历史订单预测库存
- AI加速：结合患者随访数据→预测未来3-6个月各SKU需求
- 效果：库存周转率提升30%+，缺货率降到<2%

**③ 患者流失预警：从"追回"→"预防"**
- 传统：患者不来了才发现流失
- AI加速：行为数据（预约取消频率、检查间隔拉长）→提前2个月预警
- 效果：流失率从30%降到10%以下

**④ 效果预测：配镜前就知道大概率效果**
- 传统：配了再说，3个月后复查才知道
- AI加速：输入年龄+初始度数+角膜曲率+眼轴→预测12个月控制效果
- 对门诊的价值：降低试错成本，提升家长决策信心

**⑤ 临床知识民主化：初级视光师=资深专家**
- 传统：好医生稀缺，门诊靠老板一个人
- AI辅助：初级视光师用CDSS≈有资深专家在旁指导
- 对行业的价值：解决了近视防控最根本的人才瓶颈

### 7.2 AI时代的新打法

**传统打法（2020-2025）：** 系统→数据→AI（串行，慢）

**AI原生打法（2026+）：** AI+系统+数据并行，互相增强

```
                    传统路径                    AI原生路径
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Phase 1             建系统(12个月)              用AI辅助建系统(4个月) ✅
Phase 2             积累数据(12个月)            边部署边用AI标注+训练
Phase 3             做AI(12个月)                AI已经在用，持续进化
总周期              36个月                      12-18个月 ✅
```

**你现在正在做的事本身就是AI加速的最好证明：**
- Claude帮你写代码→系统开发速度3-5x
- CDSS用RAG→不需要从零写知识库
- 飞书自动化→运营效率10x
