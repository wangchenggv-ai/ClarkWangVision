# 愤怒的小鸟 · Blu 的冒险

浏览器版小游戏 — HTML5 Canvas + Matter.js，单文件无依赖（Matter.js 走 CDN）。

## 启动

直接双击 `index.html` 用浏览器打开即可（需要联网加载 Matter.js CDN）。

## 操作

- **按住鼠标左键** 拖动弹弓瞄准，**松开** 发射
- **飞行中单击左键** 触发当前小鸟的技能（每只鸟仅能触发一次）

## 8 种小鸟

| Emoji | 名字 | 技能 |
|-------|------|------|
| 🦜 | **Blu** （开局赠送） | 空中二段加速冲刺 |
| 🐦 | Red | 普通攻击（稳定） |
| 💛 | Chuck | 瞬间加速直线俯冲 |
| 💣 | Bomb | 爆炸冲击波 |
| 🥚 | Matilda | 下蛋重力炸弹 |
| 🔴 | Terence | 变大撞击 |
| 🎀 | Stella | 泡泡吸附上浮 |
| 🧊 | Ice | 冰冻木块/猪 |

## 10 关卡

- 第 1～4 关：循序渐进
- 第 5 关：👹 中期 BOSS（紫猪，半径 48，HP 6）
- 第 6～9 关：加入冰鸟、泡泡鸟、大红
- 第 10 关：👹 最终 BOSS（超大紫猪，半径 70，HP 10）
