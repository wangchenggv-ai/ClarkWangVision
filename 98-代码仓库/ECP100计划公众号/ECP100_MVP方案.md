# ECP 100 视光师激励计划 · MVP 执行方案

**活动周期**：2026.6.15 — 2026.10.8（约16周）
**负责人**：市场总监主执行，Clark 负责门店谈判

---

## 一、核心逻辑（一句话版）

> 消费者到店取镜时，视光师用专属二维码帮消费者**扫码验真+绑定订单**，一个动作完成两件事：消费者获得正品保障和随访服务，视光师累计一份业绩。

---

## 二、消费者端体验流程

```
消费者购买镜片（线上下单 / 线下购买）
    ↓
到店试戴、交付
    ↓
视光师引导："扫码可以验证正品，后续复查也会提醒您"
    ↓
消费者扫描视光师专属二维码
    ↓
┌─ 动作A：消费者侧
│   ├ 1. 关注高视星公众号
│   ├ 2. 自动推送验真结果（产品型号 + 正品标识）
│   ├ 3. 绑定订单（自动关联该视光师）
│   └ 4. 进入随访提醒队列（3个月/6个月复查提醒）
│
└─ 动作B：系统侧
    ├ 1. 该视光师业绩 +1
    ├ 2. 数据写入飞书多维表格
    └ 3. 消费者-视光师-门店 三方绑定
```

## 三、视光师端激励体系

### 3.1 阶梯奖励

| 累计副数 | 奖励 | 备注 |
|---------|------|------|
| 50副 | 品牌礼品（价值1000元） | 第一个里程碑 |
| 70副 | 高端礼品（价值3000元） | 中期冲刺 |
| 100副 | **4天3夜出国游学** | 终极目标 |

> 游学名额封顶 **50人**，先达标先得

### 3.2 视光师专属二维码

- 每位视光师一个固定二维码，长期有效
- 命名规则：`城市-门店-姓名`（如 `上海-宝岛南京路-张明`）
- 由市场总监在公众号后台统一批量生成
- 二维码贴在视光师工位 / 胸牌背面 / 名片上

### 5.5 二维码批量生成流程

1. 收集首批签约门店的视光师名单（姓名 + 门店）
2. 公众号后台 → 渠道二维码 → 批量创建，参数 = 视光师ID
3. 统一设计二维码物料（桌贴 + 胸牌贴 + 名片）
4. 打包寄送至各门店

## 六、门店谈判要点

### 对老板说的三个价值

1. **免费绩效看板** — 你的视光师卖了多少，数据实时可见，随时导出
2. **消费者锁在你店** — 复查提醒和优惠券只能在你的门店核销，流量跑不了
3. **服务我们做** — 保养提醒、复查通知、患教内容全部由高视星公众号推送，你的员工零负担

### 标准话术

> "我们给每个视光师一个专属二维码，消费者扫码就能验证正品、绑定订单。消费者后续收到的复查提醒和优惠券都指向你的门店。你什么都不用做，数据全给你，消费者也留在你这里。"

## 八、首批签约目标

- **门店数量**：40-50家（覆盖10-15个城市）
- **视光师人数**：100人
- **预算总额**：30万（人均3000元）
- **预期达标分布**：
  - 100副（游学）：10-15人
  - 70副（高端礼品）：15-20人
  - 50副（品牌礼品）：20-30人
  - 未达标：35-55人（无成本）
- **预算分配**：
  - 游学：15人 × 1.5万 = 22.5万
  - 70副礼品：18人 × 2500元 = 4.5万
  - 50副礼品：25人 × 800元 = 2万
  - 物料 + 机动：1万
  - **合计30万**
