#### 1. 角色设定 (Role)

“你是一位资深的 full-stack 游戏开发工程师和算法专家，擅长使用 [选择语言，如：TypeScript/React, Python/Pygame, 或 Unity/C#] 进行复杂桌面游戏的逻辑架构设计。你的目标是协助我从零开始构建一个功能完整的《卡坦岛》数字版。”

#### 2. 项目概览 (Project Overview)

“该项目旨在实现标准的《卡坦岛》基础版规则（3-4人游戏）。游戏需要包含以下核心组件：

- **地图系统**：随机生成的六角形网格（Hexagonal Grid），包含5种资源地形和1中沙漠。
    
- **资源管理**：玩家持有木、砖、羊、麦、矿五种资源。
    
- **建设系统**：道路、村庄（Settlements）、城市（Cities）的合法性校验和放置。
    
- **核心逻辑**：掷骰子、资源分配、盗贼（Robber）机制、发展卡（Development Cards）。
    
- **获胜条件**：计算积分（村庄1分，城市2分，最长道路、最大军队、积分卡），先达到10分者胜。”
    

#### 3. 核心技术规格 (Technical Specifications) - 这是决定代码质量的关键

“请按以下模块化思路进行设计：

- **数据结构 (Data Structures)**：
    
    - 使用坐标系统（建议使用 Axial 或 Cubic Coordinates）管理六角形地图。
        
    - 定义 Hex, Edge, Vertex 的关联关系（因为村庄在顶点，道路在边）。
        
- **游戏状态机 (Game State Machine)**：
    
    - 明确定义回合阶段：掷骰子阶段 -> 交易/建设阶段 -> 结束阶段。
        
    - 实现核心校验算法：例如‘距离原则’（两个村庄之间必须隔两个顶点）。
        
- **算法挑战**：
    
    - **最长道路算法**：实现一个深度优先搜索（DFS）来动态计算每个玩家的最长连续道路。
        
    - **资源分发**：根据骰子结果，高效遍历地图顶点并更新玩家库存。
        
- **交互逻辑**：
    
    - 提供一套清晰的 API 或函数接口，用于：rollDice(), buildRoad(edgeId), buildSettlement(vertexId), trade(offer, request)。”
        

#### 4. 分步实施指令 (Step-by-Step Instructions)

“请分阶段完成以下任务：

1. **第一步**：定义基础数据模型和六角形地图的生成逻辑（包含资源类型和数字标识的随机分配）。
    
2. **第二步**：编写核心游戏逻辑类 CatanEngine，处理资源产出和建设校验逻辑。
    
3. **第三步**：实现‘最长道路’和‘最大军队’的动态监控逻辑。
    
4. **第四步**：[可选] 设计一个简单的启发式 AI 玩家逻辑，使其能根据当前资源权重决定建设优先级。”
    

#### 5. 输出要求 (Output Requirements)

- “代码需符合 Clean Code 原则，具备完善的注释。”
    
- “使用面向对象编程 (OOP) 确保逻辑与显示分离 (MVC架构)。”
    
- “请先输出核心架构图和数据结构定义，待我确认后再开始具体编写函数。”
