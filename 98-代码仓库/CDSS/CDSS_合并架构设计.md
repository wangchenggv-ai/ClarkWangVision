# 高视星 CDSS V2 — 合并架构设计

> 核心原则：以视光师接诊线路为串联，销售工具是钩子，CDSS藏在后面。
> 视光师打开软件的第一个理由不是"用AI看病"，而是"用这个帮我说服患者成交"。

---

## 一、总体架构：四层三模块

```
┌────────────────────────────────────────────────────────────┐
│                    视光师工作台（桌面/iPad）                  │
│  ┌────────────┐ ┌────────────┐ ┌────────────┐ ┌─────────┐ │
│  │ ① 接诊建档 │→│ ② 患者教育 │→│ ③ 成交辅助 │→│④ 验配  │ │
│  │  录入检查  │ │  (钩子)    │ │  (成交)    │ │ 支持+   │ │
│  │            │ │            │ │            │ │ 随访    │ │
│  └────────────┘ └────────────┘ └────────────┘ └─────────┘ │
│         ↓              ↓              ↓              ↓      │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ ⑤ CDSS 引擎（后台，数据越多越准）                       │ │
│  │  RAG 相似病例检索 → 方案推荐 + 风险提示                 │ │
│  └────────────────────────────────────────────────────────┘ │
│         ↓                                                    │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ ⑥ 数据平台（FastAPI + PostgreSQL）                      │ │
│  │  患者管理/随访追踪/CSV导出/JWT认证/RBAC/多中心隔离       │ │
│  └────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

| 层 | 身份 | 核心价值 | 用户感知 |
|----|------|---------|---------|
| **①-④ 接诊工作台** | 钩子 | 视光师每天必须打开的销售工具 | 高频可见 |
| **⑤ CDSS 引擎** | 壁垒 | 藏在方案推荐和报告背后提供数据支撑 | 低频可见 |
| **⑥ 数据平台** | 基座 | 基础设施，积累的数据越多壁垒越高 | 不可见 |

## 三、模块详解

### 模块①：快速建档 + 检查录入（接诊台）

**定位**：视光师打开软件的第一个界面，快速完成患者登记和初步检查数据录入。

**设计原则**：
- 初诊模式 vs 复诊模式（一个切换开关）
- 初诊：显示全部字段；复诊：只显示随访必填字段
- 默认值智能填充（上次复查数据作为基线）
- 来源代码合并：AI-Sales DataEntry（简洁UI） + CDSS-Gemini PatientForm（完整字段） + 5000cases API（后端存储）

**核心字段**：
```
基本信息：姓名 / 年龄 / 性别 / 手机 / 主诉
家庭因素：父母近视情况 / 户外活动时间 / 近距离用眼时长
初检数据：裸眼视力 / 电脑验光 / 眼压
```

## 六、"钩子"策略总结

| 接诊阶段 | 软件动作 | 患者心理变化 |
|---------|---------|------------|
| 建档检查 | 专业数据录入 | "这家挺专业的" |
| 首诊教育 🪝 | 眼球动画+风险曲线 | "原来这么严重…" |
| 首诊教育 🪝 | 不干预后果展示 | "必须得干预了" |
| 二次面诊 🪝 | CDSS推荐+方案对比 | "这个方案最适合我" |
| 二次面诊 🪝 | 证据背书+相似病例 | "数据说话，放心了" |
| 二次面诊 🪝 | 可打印报告 | "带回去给家人看" |
| 验配 | 产品手册 | "产品正规，放心" |
| 随访 | 自动提醒+数据趋势 | "效果看得见，值得" |

**视光师每天打开软件的理由**：不用它，首诊没法向患者直观展示风险，二次面诊没法让患者快速信任方案。
**CDSS的价值**：藏在每次方案推荐的"相似病例"后面，数据越多推荐越准，飞轮越转越快。
