# 故障复盘：admin.gaushclear.com 无法访问

**日期：** 2026-04-20
**影响范围：** admin.gaushclear.com / shuang.gaushclear.com / api.gaushclear.com
**持续时间：** 约 2026-04-19 午后（DNS缓存耗尽）至 2026-04-20 08:00（修复）
**严重程度：** 高（管理后台、溯源验真、API全部不可达）

---

## Root Cause

**DNS A 记录未迁移。**

2025-02-18 域名 DNS 从原服务商迁移至华为云时，只手工添加了 `lab.gaushclear.com` 一条记录，遗漏了以下三条：

| 子域名 | 类型 | 值 |
|---|---|---|
| admin.gaushclear.com | A | 120.46.44.23 |
| shuang.gaushclear.com | A | 120.46.44.23 |
| api.gaushclear.com | A | 120.46.44.23 |

迁移后系统短期仍可访问，原因是旧 DNS 缓存（TTL）未过期。缓存陆续耗尽后域名解析失败，最终完全不可达。

**与 2026-04-19 的 mock 测试无关。** Mock 服务器绑定在 `127.0.0.1:3001`，物理隔离，未触及任何生产系统。

---

## 时间线

| 时间 | 事件 |
|---|---|
| 2025-02-18 | DNS 迁移至华为云，三条 A 记录遗漏未加 |
| 2026-04-19 09:56 | admin.gaushclear.com 最后一次正常访问记录 |
| 2026-04-19 18:11 | DNS 控制台操作 lab 记录，此时发现历史记录缺失 |
| 2026-04-19 23:15 | Mock 测试开始（localhost:3001，与生产无关） |
| 2026-04-20 07:25 | ECS 重启（重置密码排查过程中） |
| 2026-04-20 08:00 | 补加三条 A 记录，DNS 生效，恢复访问 |

---

## 修复步骤

1. 华为云控制台 → 云解析服务 → gaushclear.com
2. 添加三条 A 记录（admin / shuang / api → 120.46.44.23，TTL 300）
3. 2-3 分钟后 DNS 生效，网站恢复

---

## 经验教训

1. **DNS 迁移必须完整核对所有子域名**，迁移后用 `nslookup` 逐条验证
2. **故障归因要看时间线**，先确认时序再判断因果，避免误归因
3. 5.1 前补做：用监控工具（如 UptimeRobot）对 admin/shuang/api 三个域名设置可用性告警
