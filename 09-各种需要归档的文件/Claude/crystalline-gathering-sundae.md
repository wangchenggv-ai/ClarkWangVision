# 眼镜供应链智能系统——设计规格与实施计划

**日期：** 2026-03-26
**截止：** 2026-06-30
**技术路线：** 飞书多维表格全家桶 + 飞书自动化直调 Claude API

---

## Context

创业期眼镜生产销售公司，团队小、效率优先。当前订单在飞书多维表格中管理（一年历史数据），供应链缺乏智能化：无法自动判断交期、排产靠经验、库存没有预警、AI分析为零。

目标：以飞书为唯一平台，通过自动化规则和 Claude API 集成，构建"输入销售预测 → 自动排产 → 实时看板 → AI分析"的数据飞轮，6月30日前完成全部功能迭代。

**关键业务约束：**
- 成品生产 3–5 天；毛坯片生产 3–4 周（限速步骤）
- 模芯有使用寿命，耗尽需更换（需提前预警）
- 交付承诺：有库存 3 天，定制 5 天
- 几十个 SKU 覆盖 70% 需求
- 库存上限：3 个月销量
- 订单集中在周六、周日、周一

## 二、飞书自动化规则（5条）

### 规则1：订单创建 → 查库存 → 自动写入交期（阶段一）
- **触发：** 订单表新增记录
- **逻辑：**
  1. 查成品库存表对应SKU的「当前库存」
  2. 若 ≥ 订单数量：扣减订单数量，写入「交期类型=有货3天」，承诺交货日 = 下单日+3
  3. 若 < 订单数量（含0）：写入「交期类型=定制5天」，承诺交货日 = 下单日+5
- **作用：** 客户分享视图实时反映交期

### 规则2：库存低于安全值 → 飞书消息预警（阶段一）
- **触发：** 成品库存表「当前库存」字段更新
- **条件：** 当前库存 < 安全库存
- **动作：** 向负责人发飞书消息："⚠️ SKU-XXX 库存不足，当前[N]片，低于安全库存[M]片，建议安排排产"

### 规则3：模芯寿命预警（阶段二）
- **触发：** 模芯管理表「已使用次数」字段更新
- **条件：** 剩余次数 < 预警阈值
- **动作：** 发飞书消息："🔴 模芯[编号]剩余[N]次，对应SKU-XXX，建议尽快订购新模芯（模芯采购周期约3-4周）"

### 规则4：填入销售预测 → 自动生成排产建议（阶段二）
- **触发：** 销售预测表新增或修改记录
- **逻辑：** 对每个SKU：建议产量 = 预测量 - 当前库存 - 在产量
- **条件：** 建议产量 > 0
- **动作：** 在排产计划表新增记录（周次、SKU、建议量），状态="待确认"，触发人工确认流程

### 规则5：每周定时 → 调用 Claude API → AI分析报告（阶段三）
- **触发：** 每周一 08:00 定时
- **逻辑：**
  1. 汇总本周数据快照（库存状态、订单量、排产进度、预警项）
  2. 通过"发送HTTP请求"动作 POST 到 Anthropic Messages API
  3. Prompt 模板包含数据快照 + 分析要求（预警项、排产建议、趋势观察）
  4. 解析返回 JSON，将分析文本写入「AI分析记录表」
  5. 同步发飞书消息，附上分析摘要链接
- **注：** 飞书自动化原生支持"发送HTTP请求"动作，Claude 提供完整配置，无需编程

## 三、客户分享视图设计

在成品库存表上建立分享视图（在现有基础上完善）：
- **字段显示：** SKU名称、当前状态（有货/缺货）、承诺交期（天）
- **筛选：** 只显示「类型=备货品」的SKU
- **隐藏：** 库存数量、成本等内部字段
- **排序：** 按SKU编号
- **更新：** 实时（无需手动刷新）

客户通过固定链接访问，无需注册飞书账号。

## 六、验证方法

**阶段一验收：**
1. 在订单表新增一条有库存SKU的订单 → 确认「交期类型=有货3天」自动填入，库存-1
2. 在订单表新增一条无库存SKU的订单 → 确认「交期类型=定制5天」自动填入
3. 将某SKU库存手动改为0 → 确认收到飞书预警消息
4. 用客户分享链接查看 → 确认能看到SKU状态和交期

**阶段二验收：**
1. 在预测表填入某SKU预测量100片、当前库存30片 → 确认排产表自动生成一条「建议产量=70，状态=待确认」
2. 修改模芯已使用次数至接近阈值 → 确认收到模芯预警消息
3. 查看仪表盘 → 确认5个卡片正常显示

**阶段三验收：**
1. 手动触发规则5 → 确认Claude API调用成功，AI分析文字写入表格

3. 仪表盘AI摘要卡片 → 显示最新分析内容

## 七、技术注意事项

**飞书自动化HTTP请求配置（规则5）：**
```
POST https://api.anthropic.com/v1/messages
Header: x-api-key: [Anthropic API Key]
Header: anthropic-version: 2023-06-01
Header: content-type: application/json
Body: {
  "model": "claude-opus-4-6",
  "max_tokens": 1024,
  "messages": [{"role": "user", "content": "[数据快照 + 分析提示词]"}]
}
```
具体 Prompt 模板和完整配置在阶段三实施时由 Claude 提供。

**Anthropic API Key：** 需在 anthropic.com 注册并获取，按使用量付费（每次分析约 $0.01–0.05）。

**飞书计划版本：** 飞书自动化的"发送HTTP请求"功能需确认所在飞书版本支持（企业版/专业版通常支持）。
