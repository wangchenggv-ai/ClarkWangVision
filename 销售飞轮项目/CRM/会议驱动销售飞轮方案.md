# 会议驱动销售飞轮方案

> 基于COOC实战复盘 + 5-6月6-8场推广会需求，将市场会议从"活动"变为"可衡量的销售引擎"

---

## 一、COOC暴露的核心问题

| 环节 | 现状 | 痛点 |
|------|------|------|
| 会前邀约 | 销售Excel报名单，市场部汇总 | 名单散落各处，无法提前锁定客户 |
| 酒店住宿 | Excel手工排房，余晓玲人工核对 | 房间变动频繁，无法实时追踪 |
| 会中签到 | **纸质手写**，会后拍照OCR识别 | 信息不全（12条无单位手机号），录入慢 |
| 会后统计 | 助理手工去重，交付2个Excel | 耗时耗力，77家机构手工核对 |
| 客户跟进 | 总结会提了"一对一跟进"但无系统 | COOC结束至今无跟进记录 |
| 效果归因 | **完全没有** | 不知道哪场会→哪些客户→产生了多少订单 |

**COOC数据**：4.9会议139人/77家机构，4.10会议29人/16家机构，99间房。这些数据→CRM只有13条（刚才才录入的）。

## 三、会前：客户锁定数字化

### 3.1 邀约名单从CRM出

**流程**：
1. 销售从CRM 02表筛选负责区域的客户
2. 标记"邀请参会"字段（新增select：是/否）
3. 自动汇总到市场会议主表的参会客户名单

**新增02表字段**：
- 是否邀请参会（select: 是/否）
- 最近参会日期（datetime）
- 累计参会次数（number）

**好处**：不用每次会前重新报Excel名单，直接从CRM拉。COOC的77家机构如果已入CRM，一键筛选即可。

### 3.2 提前录入住宿信息

酒店/房型/入住日期/离店日期，销售在CRM中直接维护，市场部实时可见。

## 四、会中：二维码扫码签到

### 4.1 方案设计

**飞书表单二维码**（最简方案，零开发）：

1. 在飞书多维表格中为"市场会议客户名单表"创建一个**登记表单**
2. 表单字段：
   - 姓名（text，必填）
   - 手机号（text，必填）
   - 单位名称（text，必填）
   - 参会场次（select：4.9学术会/4.10卫星会/同时参加）
   - 邀请销售（select：徐征颖/尹建华/余晓玲/高珊）
   - 所属代理商（select，从01表拉取）
3. 生成二维码 → 会场入口/桌牌/屏幕展示
4. 客户扫码填表 → **实时写入CRM**，无需会后OCR录入

### 4.2 对比

| | 纸质签到+OCR | 飞书表单扫码 |
|---|---|---|
| 数据质量 | 不全（无单位12条） | 必填字段强制校验 |
| 录入速度 | 会后1-2天手工处理 | **实时自动** |
| 去重 | 手工 | 自动关联已有客户 |
| 成本 | 0 | 0 |
| 会中可见性 | 无 | 实时看签到人数 |

### 4.3 进阶（未来可选）

- 飞书小程序签到（扫码自动定位客户，点一下即可）
- 会议不同场次不同二维码
- 展台互动扫码（扫码看产品资料→记录兴趣点）

## 五、会后：自动归因引擎

### 5.1 归因逻辑

```
会议结束 → 开始30天计时 → 该会议关联的所有客户 → 期间新订单自动归因
```

具体实现（rule7）：
1. 会议主表"会议状态"改为"已完成"
2. 每日凌晨扫描：参会客户名单中每个客户，在会议日期+30天内是否有新订单
3. 汇总出单金额 → 回写"会后30天出单额"
4. 自动计算会议ROI

### 5.2 客户维度追踪

在02终端客户表中新增：
- 最近参会日期（datetime）
- 参会后是否出单（select: 是/否）
- 参会后出单金额（number）
- 参会后出单天数（number）= 首单日期 - 参会日期

### 5.3 销售维度追踪

按销售聚合：
- 该销售带了多少客户参会
- 这些客户会后出单率
- 这些客户会后出单金额
- 客户平均转化天数

## 六、5-6月6-8场会的执行节奏

### 每场会的标准流程

| 时间 | 动作 | 负责人 | 系统支撑 |
|------|------|--------|---------|
| T-14天 | CRM筛选邀请客户，标记"邀请参会" | 销售 | 02表新增字段 |
| T-7天 | 汇总参会名单，订酒店 | 市场部 | 会议主表建记录 |
| T-3天 | 生成签到二维码，打印桌牌 | 市场部 | 飞书表单 |
| T日 | 会场入口扫码签到 | 客户自助 | 表单实时写入 |
| T+1天 | 数据核对（系统自动） | 市场部 | 对比计划vs实际 |
| T+7天 | 首轮跟进完成 | 销售 | CRM更新阶段 |
| T+30天 | 自动计算出单归因 | 系统 | rule7 |

- 全流程跑通（会前CRM筛选→扫码签到→会后归因）
- 发现问题立即优化

## 十、COOC数据的处置

COOC是已经结束的会，但数据有价值：

1. **77+16家机构** → 批量录入02终端客户表（标注来源=COOC 2026）
2. **关联销售** → 根据入住名单中的渠道负责人自动分配客户所有人
3. **关联代理商** → 根据入住名单中的代理商字段关联01表
4. **补建会议主表记录** → COOC作为第一笔数据，建立基准线
5. **30天后（5月20日）** → 回溯COOC参会客户是否出单，算出首场会的ROI基准

这样5-6月的推广会就有对比基准了。
