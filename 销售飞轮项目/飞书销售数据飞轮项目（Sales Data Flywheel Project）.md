# 飞书销售数据飞轮项目（Sales Data Flywheel Project）

**文档版本**：V2.0（2026年4月10日修订）
**启动日期**：2026年4月4日
**目标完成日期**：2026年6月30日
**项目负责人**：Clark Wang
**CRM管理员**：沈锋（数据质量、系统维护、日常运营）
**参与人员**：4名销售（尹建华/余晓玲/徐征颖/高珊）+ 市场部

**核心目标**：以飞书多维表格为底座，打通终端客户、订单、培训、市场会议四类数据，实现销售管道可视化、城市会数据化管理、培训转化率追踪，支撑Q2-Q3业务增长。
