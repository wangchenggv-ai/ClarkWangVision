# 供应链订单系统 — 项目总览

> **最后更新：** 2026年5月1日  
> **定位：** 本项目唯一入口文档，看完这个就知道所有事情

---

## 一、项目背景

高视星/Gaush 离焦镜片供应链。2026年寒假高峰暴露问题：

- 超期率50%（Ultra近60%），日均交付70副 vs 订单100副
- Ultra/小旋风零库存，订单全流程依赖微信群+手工Excel
- 车房产能瓶颈，模芯单点故障风险

**项目周期：** 2026年3月24日 → 6月30日（100天）

## 四、系统架构速览

```
┌─ 代理商 ─────────────────────────────┐
│  order.html(网页) / Excel发送给助理    │
└────────────────┬─────────────────────┘
                 ▼
┌─ server.js (Node.js, 华为云 ECS) ────┐
│  lab.gaushclear.com:3210             │
│                                      │
│  API: submit / confirm / ship / ...  │
│  前端: order / track / labels / ...  │
│  草稿缓冲: 本地JSON → 30min同步      │
│  库存+交期: lib/stock.js (缓存2min)   │
│  物流: logistics.js (快递回调)        │
│  打印: 队列拉模式 → TCP发打印机       │
└────────────────┬─────────────────────┘
                 ▼
┌─ 飞书 Bitable ───────────────────────┐
│  App: B3xQbbqicaome1sKdZbcwdk8nWg   │
│  订单主表 / 镜片明细 / 代理商 / 客户   │
│  SKU主数据 / 度数级库存 / 排产 / 预测  │
└──────────────────────────────────────┘
```

**关键约束：** Node.js原生http模块（非Express）、ES Modules、零构建、Bitable为主存储
