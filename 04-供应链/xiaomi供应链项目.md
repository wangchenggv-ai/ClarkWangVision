## 项目状态说明

| 状态 | 含义 |
|------|------|
| **待启动** | 任务已确认，尚未开始 |
| **待测试** | 任务已完成准备，等待测试验证 |
| **待评估** | 需要开会或沟通后才能确定方案 |
| **待开会** | 需要专题会议讨论后推进 |
| **待演示** | 已安排演示，等待执行 |
| **待寄送** | 相关物料已安排，等待发货 |
| **待确认** | 已采取行动，等待外部反馈 |
| **进行中** | 任务正在执行中 |
| **已下单待确认** | 采购/下单已完成，等待交期确认 |
| **规划中** | 已纳入规划，等待合适时机启动 |
| **探索中** | 长期方向性探索，尚未进入执行阶段 |
| **已完成** | 任务完成并验收通过 |
