> **目标**：交付质量与服务达到暑假高峰日均100+副的能力，超期率从50%降至20%以下

## 二、逐环节拆解

### 1. 接单（客户 → 公司）

| 维度 | 内容 |
|------|------|
| **负责人** | 胡瑞雪（接单）、谢碧琪（录入飞书） |
| **现状痛点** | 微信群下单→人工录飞书，漏单/重复下单；客户咨询回复不及时；查单覆盖下单Excel导致漏单 |
| **基线指标（待补）** | 日均接单量、漏单率、接单→录入平均耗时、客户平均响应时间 |
| **适用实践** | ④订单可视化 + ⑤防错设计 |
| **AI介入方案** | 飞书机器人自动汇总微信群订单→生成Excel→贴入飞书多维表格；AI机器人自动回复"订单已收到+预计发货时间" |
| **防错设计** | 订单模板增加必填校验（度数范围、左右眼、地址格式）；订单群与售后群分离 |
| **改进目标** | 漏单率→0%；客户咨询响应时间<30分钟；接单到录入时效<2小时 |

---

### 2. 订单处理与下发（公司 → 车房）

| 维度 | 内容 |
|------|------|
| **负责人** | 谢碧琪（订单处理、二维码制作） |
| **现状痛点** | 手工对照Excel逐条发车房；二维码制作程序繁琐（手动输参数、升码下载、解压）；两家工厂接单方式不统一（圣谱要单个订单表，九次方要压缩包） |
| **基线指标（待补）** | 日均处理订单数、单笔订单处理耗时、二维码制作耗时、下单错误率 |
| **适用实践** | ④订单可视化 + ⑤防错设计 + ⑥供应商协同 |
| **AI介入方案** | 订单自动分拣（按产品类型/参数自动分配车房）；二维码批量生成（AI替代手工输参数）；统一下单格式（飞书导出标准Excel，各车房自行下载） |
| **防错设计** | 正度数、冷净度、特殊装配要求自动高亮标注；装配/不装配订单系统自动分类 |
| **改进目标** | 单笔订单处理时间缩短50%；下单错误率→0%；统一下单接口 |

---

### 3. 备库与排产（库存决策）

| 维度 | 内容 |
|------|------|
| **负责人** | 沈锋（整体）、王成（代理商备库） |
| **现状痛点** | Ultra零库存、小旋风零库存、时空之眼部分参数断货；备库靠经验，无数据模型；模芯单点故障风险（小旋风仅1颗模芯） |
| **基线指标（待补）** | 各产品安全库存达标率、SKU覆盖率、缺货率、库存周转天数 |
| **适用实践** | ①需求预测 + ②推拉结合点 + ③瓶颈管理 + ⑥供应商协同 |
| **需求预测方案** | 基于7000副历史数据做ABC-XYZ分类：按SKU销量（A/B/C）× 需求波动性（X/Y/Z）分9格，AX类直接备库存片，CZ类只做零单 |
| **推拉结合点** | 毛坯片→推式备库（Ultra季度5000片，小旋风1000片）；成品片→高频SKU推式备库存片（目标覆盖50-70%订单量），低频SKU拉式按单生产 |
| **备库目标** | Ultra安全库存2000片（车房备片4400片）；小旋风安全库存500片（车房备片400片）；时空之眼AB各补900片 |
| **改进目标** | SKU覆盖率达50%+（Phase 1）→70%（Phase 3）；库存片订单交期缩短至2-3天 |

---

### 4. 生产制造（车房执行）

| 维度 | 内容 |
|------|------|
| **负责人** | 沈锋（车房管理）、唐洁琼（产品质量） |
| **现状痛点** | 圣谱产能有限（日产60-90副）；九次方排队3-5天；模芯不稳定（4颗模芯能否使用待确认）；白点问题影响质量 |
| **基线指标（待补）** | 各车房日产能、生产周期（接单→完成）、良品率、产能利用率 |
| **适用实践** | ③瓶颈管理 + ⑤防错设计 + ⑥供应商协同 |
| **瓶颈管理** | 核心动作：切换欧陆（可接批量单，预计日处理能力3000片）；圣谱转为备份角色（零单+少量批量）；评估北京装配中心 |
| **供应商协同** | 向欧陆共享订单预测和库存数据，推动VMI简化版（供应商主动排产备货）；学习欧陆"10人→1人"的AI订单处理经验 |
| **质量改进** | 唐洁琼+沈锋研究深浅/对比度问题（照相机+夹具+算法）；产品使用8000次后效果跟踪 |
| **改进目标** | 总产能满足日均100+副；生产周期（零单）控制在5天内 |

---

### 5. 订单跟踪（生产中 → 发货前）

| 维度 | 内容 |
|------|------|
| **负责人** | 唐洁琼（订单状态更新） |
| **现状痛点** | 无法直接查圣谱系统，靠人工导Excel对照；状态滞后，查询与实际不符；飞书订单表逐条对应Excel耗时且易漏 |
| **基线指标（待补）** | 订单状态更新频率、状态准确率、超期订单发现时效 |
| **适用实践** | ④订单可视化 + ⑥供应商协同 |
| **控制塔方案** | 飞书多维表格作为"单一真相源"：每个订单一行，状态字段包括（接单→已下车房→生产中→完成→待发货→已发货→签收）；车房每日导出数据自动同步 |
| **AI介入方案** | AI机器人自动识别和更新订单状态；超期预警（接近交期自动提醒）；库存片订单跳过跟踪环节直接发货 |
| **改进目标** | 订单状态实时准确率>95%；超期订单24小时内预警 |

---

### 6. 装配与发货（成品 → 客户）

| 维度 | 内容 |
|------|------|
| **负责人** | 杨丹/高静（装配）、唐洁琼（发货状态） |
| **现状痛点** | 镜架到货存放混乱；手动打标签易错、不同产品标签未分开；装配/不装配易混淆导致遗漏；发货地址错误；随货单格式不统一 |
| **基线指标（待补）** | 发货准确率、发货时效（完成→发出）、装配订单遗漏率、地址错误率 |
| **适用实践** | ④订单可视化 + ⑤防错设计 |
| **防错设计** | 镜架按日期分类存放（到货日期标签）；标签系统自动生成（杜绝手工打印）；装配/不装配用颜色标签区分（如蓝色=装配，白色=不装配）；随货单统一模板（只需改参数/度数/姓名/数量） |
| **流程优化** | 扫码发货（系统链接→扫码→自动匹配快递单号→更新状态）；客户必须提供快递单号才能下装配订单 |
| **改进目标** | 发货准确率>99%；发货时效（完成→发出）<24小时 |
