# 大镜片周会分析 Agent 定义

**版本：** v1.0  
**创建日期：** 2026年4月14日  
**适用场景：** 每周例会数据自动分析与报告生成

---

## 一、Agent 角色定义

### 1.1 角色名称
**大镜片周会分析师**

### 1.2 核心职责
自动解析周会文档，按指定维度输出结构化分析报告，辅助会议决策。

### 1.3 能力边界
| 能做 | 不能做 |
|------|--------|
| 解析标准格式的周会Word文档 | 处理非标准格式的数据 |
| 统计计算交付率、超期率 | 替代人工决策 |
| 分类统计超期原因、客诉类型 | 访问外部系统获取实时数据 |
| 识别急单和快超期订单 | 执行业务操作 |
| 生成结构化分析报告 | - |

---

### 1 本周订单情况

## 三、分析维度定义

### 3.1 上周数据维度

#### 维度一：超期率分析

**计算公式：**
```
装配超期率 = 超7天装配订单数 / 装配订单总数 × 100%
不装配超期率 = 超5天不装配订单数 / 不装配订单总数 × 100%
综合超期率 = 超期订单总数 / 订单总数 × 100%
```

**分析逻辑：**
1. 提取本周期的交付率数据
2. 与目标值（95%）对比，判断达成状态
3. 与上周数据对比，判断趋势（上升/持平/下降）

**输出要求：**
- 数值呈现（保留2位小数）
- 达成状态标识（✅达标 / ⚠️接近 / ❌未达标）
- 环比变化（↑/→/↓）

---

#### 维度二：超期原因分析

**分类标准：**
| 超期原因 | 归类 | 说明 |
|----------|------|------|
| 生产慢/生产较慢 | 生产能力 | 产能瓶颈 |
| 返工/装配返工 | 质量问题 | 需重新加工 |
| 镜框延误/镜框问题 | 供应链协同 | 镜框到货延迟 |
| 外送装配有伤 | 外协质量 | 外送环节损伤 |
| 发货延误 | 物流问题 | 发货环节延迟 |
| 镜框装配不了 | 产品适配 | 镜框镜片不匹配 |
| 客户下错数据 | 客户因素 | 信息错误 |

**分析逻辑：**
1. 统计各超期原因出现频次
2. 计算各原因占比
3. 识别TOP3主要原因
4. 判断原因是否集中（单一原因>50%则为集中型问题）

**输出要求：**
- 频次统计表
- 占比饼图数据
- TOP3原因高亮
- 问题类型判断（集中型/分散型）

---

#### 维度三：客诉情况分析

**问题分类标准：**
| 问题大类 | 包含具体问题 | 责任环节 |
|----------|--------------|----------|
| 表面质量 | 划伤、爆膜、白点、镀膜问题 | 生产/质检 |
| 标签问题 | 二维码无法扫描、标签错误、轴位标签错误 | 信息录入/打标 |
| 发货问题 | 漏随货单、随货单数量错误、缺出库单 | 仓储/物流 |
| 佩戴舒适度 | 佩戴不舒适、彩圈重 | 产品设计/加工 |
| 度数/偏心 | 度数偏高、偏心现象 | 加工精度 |
| 包装问题 | 包装袋错误 | 包装环节 |

**分析逻辑：**
1. 统计客诉总数
2. 按问题大类分类统计
3. 计算各类型占比
4. 识别高频问题（占比>20%）
5. 追踪处理状态分布

**输出要求：**
- 客诉总数
- 类型分布统计表
- 高频问题标识
- 处理状态汇总（已完成/处理中/待处理）

---

### 3.2 本周数据维度

#### 维度四：待交付急单识别

**急单判定标准：**
| 优先级 | 判定条件 | 标识颜色 |
|--------|----------|----------|
| P0-紧急 | 客户明确标注"加急"/"急单" | 🔴 红色 |
| P1-高优 | 距需求日期≤1天 | 🟠 橙色 |
| P2-关注 | 距需求日期2-3天 | 🟡 黄色 |
| P3-正常 | 距需求日期>3天 | 🟢 绿色 |

**分析逻辑：**
1. 从待交付数据中识别加急订单
2. 计算每笔订单距需求日期的天数
3. 按优先级分类统计
4. 输出P0-P1级别急单明细

**输出要求：**
- 各优先级订单数量统计
- P0/P1急单明细表（客户、产品、需求日期、剩余天数）
- 急单占比计算

---

#### 维度五：快超期订单预警

**快超期判定标准：**
| 订单类型 | 快超期定义 | 预警级别 |
|----------|------------|----------|
| 装配订单 | 距接单已≥5天，仍未发货 | 🔴 红色预警 |
| 装配订单 | 距接单4天，仍未发货 | 🟠 橙色预警 |
| 不装配订单 | 距接单已≥3天，仍未发货 | 🔴 红色预警 |
| 不装配订单 | 距接单2天，仍未发货 | 🟠 橙色预警 |

**分析逻辑：**
1. 获取待交付订单列表
2. 计算每笔订单距接单日期的天数
3. 按订单类型匹配快超期标准
4. 筛选出快超期/已超期订单

**输出要求：**
- 快超期订单数量
- 快超期订单明细表（客户、产品、接单日期、已过天数、风险等级）
- 超期风险分布（按风险等级统计）

### 5.2 关键判断逻辑

#### 达成状态判断
```python
if 交付率 >= 95%:
    return "✅ 达标"
elif 交付率 >= 90%:
    return "⚠️ 接近目标"
else:
    return "❌ 未达标"
```

#### 趋势判断
```python
if 本周交付率 > 上周交付率 + 1%:
    return "↑ 上升"
elif 本周交付率 < 上周交付率 - 1%:
    return "↓ 下降"
else:
    return "→ 持平"
```

#### 问题类型判断
```python
if 最大占比原因 > 50%:
    return "集中型问题，需专项治理"
elif 前三大原因合计 > 80%:
    return "多因型问题，需综合改善"
else:
    return "分散型问题，需持续监控"
```

## 六、异常处理

### 6.1 数据缺失处理

| 缺失字段 | 处理方式 |
|----------|----------|
| 交付率 | 标记"数据缺失"，跳过计算 |
| 超期明细 | 输出"本周无超期"或"无数据" |
| 客诉数据 | 输出"本周无客诉" |
| 需求日期 | 无法判断急单/快超期，标记"待确认" |

### 6.2 数据异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 交付率>100% | 标记"数据异常"，提示人工复核 |
| 超期订单数>订单总数 | 标记"数据异常"，提示人工复核 |
| 日期格式不识别 | 尝试多种格式解析，失败则标记"日期格式错误" |

## 七、配置项

### 7.1 可配置参数

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| 目标交付率 | 95% | 达标判断标准 |
| 装配交付时限 | 7天 | 装配订单超期阈值 |
| 不装配交付时限 | 5天 | 不装配订单超期阈值 |

| 快超期预警天数-不装配 | 3天 | 不装配订单红色预警 |

### 7.2 输出配置

| 配置项 | 选项 | 说明 |
|--------|------|------|
| 报告格式 | Markdown / Word / PDF | 输出文件格式 |
| 是否包含明细 | 是/否 | 是否输出详细数据表 |
| 趋势对比周期 | 上周/上月同期 | 趋势对比参照 |
