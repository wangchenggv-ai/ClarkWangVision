# 供应链14周执行追踪 Skill

**创建日期：** 2026年3月27日  
**触发条件：** 提到供应链进度、沈锋、交付、逾期率、AI Native项目、备库

---

## 功能一：周度数据更新

### 触发方式
用户说"更新供应链数据"、"本周进度"、"沈锋汇报"。

### 执行步骤
1. 要求输入本周关键指标（准时交付率、逾期订单数、在途库存、备库到位率）
2. 与上周对比，标注改善/恶化
3. 计算14周目标的当前进度百分比
4. 输出偏差分析和建议action

### 输出模板

```markdown
## 第X周进度（日期）

| 指标 | 本周 | 上周 | 趋势 | 14周目标 | 达成率 |
|------|------|------|------|---------|--------|
| 准时交付率 | | | ↑/↓ | ≥95% | |
| 逾期订单数 | | | ↑/↓ | ≤5 | |
| 备库到位率（北区） | | | ↑/↓ | 100% | |

### 本周偏差
- [偏差描述 + 根因]

### 建议Action
- [具体行动 + 负责人 + 截止日]
```

## 功能二：里程碑检查

### 关键里程碑

| 里程碑 | 截止日 | 验收标准 |
|--------|--------|---------|
| 铂林/大光明质量问题闭环 | 4月底 | 根因报告+纠正措施落地 |
| 北区备库试点上线 | 5月1日 | 备库清单确认+首批到货 |
| 5.1交付保障 | 5月1日 | 高峰期准时交付率≥95% |
| 暑假交付保障 | 7月1日 | 产能预留+库存预备完成 |
| 销售支持系统需求解决 | 4月30日 | 联合财务和工厂闭环 |

### 触发方式
用户说"检查里程碑"、"哪些到期了"。

---

## 功能三：CEO决策预警

当以下情况出现时，自动提醒CEO介入：
- 准时交付率连续2周低于85%
- 逾期订单数连续2周上升
- 里程碑逾期超过1周无闭环
- 沈锋未按时提交周报

## 与其他Skill的协同

- **销售月会Skill**：月会前自动拉取最新供应链数据，生成交付情况简报
- **1-on-1 Skill**：如面谈中涉及交付投诉，引用供应链最新数据

## 迭代说明

每4周回顾一次Skill效果，根据实际执行调整指标阈值和预警规则。
