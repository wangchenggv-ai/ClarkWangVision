## 一、系统概览

订单系统覆盖从代理商下单到消费者扫码验真的全链路闭环。

### 状态机

```
提交订单 → 已下单 → 待处理 → 生产中 → 打标签 → 已发货（终态）
```

**三条路径：**
- **A 有库存**：已下单 → 打标签 → 已发货（跳过待处理+生产中）
- **B 无库存外发**：已下单 → 待处理 → 生产中 → 打标签 → 已发货
- **C 供应商直发**：已下单 → 待处理 → 生产中 → 已发货（跳过打标签）

### 三端用户

| 角色 | 页面 | 职责 |
|------|------|------|
| 代理商 | 下单页 / 追踪页 | 提交订单、查看进度、复制快递单号 |
| 助理（管理员） | 订单管理 / 标签打印 | 确认、打印标签、发货、导出 Excel |
| 消费者 | 验真页 | 扫码验证镜片真伪 |

## 三、第一步：代理商下单

**入口：** `https://lab.gaushclear.com/order?t={代理商Token}`

### 3.1 填写收货信息

| 字段 | 说明 | 必填 |
|------|------|------|
| 终端客户 | 输入客户名称，自动联想已有客户 | ✅ |
| 联系人 | 收货联系人 | ✅ |
| 联系电话 | 手机号 | ✅ |
| 收货地址 | 详细地址 | ✅ |

> 选择已有的终端客户后，联系人/电话/地址会自动填充。

### 3.2 添加顾客订单

点击「+ 添加顾客」按钮，为每个顾客填写：

| 字段 | 说明 |
|------|------|
| 顾客姓名 | 患者姓名 |
| 产品型号 | 下拉选择：时空之眼A/B/PRO/MAX、小旋风、Ultra双效、D8 等 |
| 数量 | 默认 1 |
| 右眼 / 左眼 | SPH（球镜）、CYL（柱镜）、AXIS（轴位） |
| 是否装配 | 是 / 否 |
| 备注 | 可选 |

**快捷操作：**
- 「复制右眼到左眼」— 双眼度数相同时使用
- 「删除」— 移除该顾客卡片
- 「上传Excel」— 批量导入处方数据

### 3.3 处方规范

| 参数 | 范围 | 说明 |
|------|------|------|
| SPH（球镜） | -20.00 ~ 0 | 近视度数，输入正数会自动转为负数 |
| CYL（柱镜） | -6.00 ~ 0 | 散光度数 |
| AXIS（轴位） | 1 ~ 180 | 散光轴位角度 |

> 系统会自动校验异常值并提示，但仍允许提交。

### 3.4 提交订单

1. 检查「订单摘要」区域，确认顾客数量和镜片数量
2. 点击「提交订单」
3. 在确认弹窗中核对信息
4. 点击「确认提交」
5. 提交成功后显示订单编号（格式：`ORD-YYYYMMDD-XXXXXX`）

**注意事项：**
- 提交后不可修改，请仔细核对
- 页面每 3 秒自动保存草稿到浏览器，意外关闭可恢复
- 同一订单号可包含多个顾客（多人合并下单）

## 四、第二步：助理确认订单

**入口：** `https://lab.gaushclear.com/orders?admin=GaushOrderMock`

### 4.1 查找订单

- 点击顶部状态卡片快速筛选（如点击「已下单」只看待确认的订单）
- 或使用筛选栏：日期范围、代理商、产品型号、关键词搜索

### 4.2 确认订单

**单个确认：**
1. 在订单行找到状态为「已下单」的订单
2. 点击操作列的「待确认」按钮
3. 系统自动完成：
   - 生成镜片码（16位大写HEX，每只眼一个）
   - 生成二维码（绑定到镜片码）
   - 计算交期（有货1-2天 / 排产5-7天 / 定制7-10天）
   - 状态更新为「待处理」（无库存外发）或「打标签」（有库存）

**批量确认：**
1. 勾选多个订单
2. 点击底部操作栏的「确认下单」按钮

### 4.3 查看详情

点击订单行左侧的「▶」展开按钮，可以看到：
- 处方明细表（眼别、SPH、CYL、AXIS、镜片码）
- 库存状态（下拉可改）
- 供应商（下拉可改）
- 流程进度条（5步 stepper）

### 4.4 退回操作

如果订单信息有误，可以逐级退回：
- 生产中 → 待处理
- 待处理 → 已下单（清除镜片码）
- 打标签 → 已下单（清除镜片码）

> ⚠️ 退回会清除镜片码，需要重新确认生成。已发货的订单不可退回。

## 五、第三步：导出 Excel 给工厂

确认订单后，需要将处方数据导出为 Excel 发给工厂生产。

### 5.1 在订单管理页导出

1. 勾选需要导出的订单
2. 点击底部操作栏的「导出Excel给工厂」
3. 浏览器自动下载 Excel 文件

### 5.2 在标签打印页导出

1. 勾选需要导出的订单
2. 点击底部操作栏的「导出Excel」
3. 浏览器自动下载 Excel 文件

### 5.3 导出格式

导出的 Excel 包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 姓名 | 顾客姓名 | 张三 |
| 型号 | 产品型号 | 时空之眼A |
| 眼别 | 右眼/左眼 | 右眼 |
| 球镜 | SPH 度数 | -2.25 |
| 柱镜 | CYL 度数 | -0.50 |
| 轴位 | AXIS 角度 | 150 |
| 二维码 | 验真链接 | https://lab.gaushclear.com/verify/F1024... |
| 日期 | 订单创建日期 | 2026-04-28 |

> 此 Excel 格式可直接导入其他标签打印机系统。

## 六、第四步：打印标签

**入口：** `https://lab.gaushclear.com/labels-print?admin=GaushOrderMock`

### 6.1 方式一：扫码打印（推荐）

1. 确保扫码模式为「打印标签」（左上角切换）
2. 用扫码枪扫描镜片包装上的条形码
3. 系统自动：
   - 识别镜片码
   - 将订单状态更新为「打标签」
   - 将标签加入打印队列
4. 本地 pull-print.js 守护进程自动拉取并发送到斑马打印机

### 6.2 方式二：批量打印

1. 筛选状态为「生产中」或「打标签」的订单
2. 勾选需要打印的订单
3. 点击底部操作栏的「打印标签」（浏览器打印）或「斑马打印」（斑马打印机队列）

### 6.3 方式三：单张打印

在订单行点击「🖨」打印按钮，单独打印该订单的标签。

### 6.4 预览标签

1. 勾选订单
2. 点击「预览标签」
3. 页面下方显示标签预览卡片（含条形码、QR码、处方信息）

### 6.5 导出 Excel（供其他打印机）

1. 勾选订单
2. 点击「导出Excel」
3. 下载的 Excel 格式与标签数据库模板一致

### 6.6 分仓模式

1. 切换扫码模式为「分仓」
2. 扫描镜片码
3. 系统按收货地址自动分配到对应仓位
4. 仓位面板显示各仓位的镜片分布

### 6.7 打印机配置

展开「打印机配置」区域：
- 连接方式：TCP 网络 / USB 桥接
- 打印机IP：默认 192.168.0.208
- 端口：默认 9100
- 份数：默认 1

配置保存后，点击「检测连接」确认打印机在线。

## 七、第五步：发货

### 7.1 单个发货

1. 在标签打印页，找到状态为「打标签」的订单
2. 点击操作列的「🚚」发货按钮
3. 确认弹窗中点击「确定」
4. 系统自动生成快递单号，状态更新为「已发货」
5. 飞书通知自动推送给代理商

### 7.2 批量发货

1. 勾选多个订单
2. 点击底部操作栏的「确认发货」
3. 确认后批量生成快递单号

### 7.3 同行单

发货后可以生成随货同行单（装箱单）：
1. 勾选已发货的订单
2. 点击「同行单」
3. 浏览器打开同行单页面，可打印或导出 PDF

同行单包含：订单号、顾客、代理商、处方明细、快递单号、签收栏。

## 九、第七步：消费者验真

**入口：** 扫描镜片包装上的二维码，自动跳转到验真页面。

URL 格式：`https://lab.gaushclear.com/verify/{镜片码}`

### 9.1 验真结果

**验证通过（绿色页面）：**
- 显示「正品验证通过」
- 订单号
- 产品名称
- 处方信息（眼别、SPH、CYL、AXIS）
- 验证时间

**未找到（红色页面）：**
- 显示「未找到记录」
- 提示「此镜片码未在系统中登记，请联系授权销售商确认产品真伪」

### 9.2 验真原理

```
消费者扫码 → 镜片码 → 镜片明细表查询 → 订单编号 → 订单主表 → 显示验真结果+处方信息
```

- 每个镜片码全球唯一（16位大写HEX）
- 镜片码在助理确认订单时生成，终生不变
- 验真页面无需登录，任何人都可访问

## 十、常见问题

### 下单相关

**Q: 同一个顾客下了两副相同型号的镜片，怎么区分？**
A: 系统用「订单编号 + 顾客姓名 + 序号」区分，序号自动递增。

**Q: 下单后发现处方填错了怎么办？**
A: 联系助理在管理后台退回订单到「已下单」状态，代理商可重新下单。

**Q: 可以一次下单多个顾客吗？**
A: 可以，一个订单最多包含 20 个顾客。

### 确认相关

**Q: 确认订单后镜片码在哪里看？**
A: 在订单管理页点击「▶」展开，处方明细表中有镜片码列。

**Q: 镜片码可以重新生成吗？**
A: 不可以。镜片码一旦生成终生不变。如需更换，只能退回后重新确认。

### 标签相关

**Q: 标签打印出来模糊怎么办？**
A: 检查打印机分辨率设置，斑马打印机建议 203dpi 以上。

**Q: 扫码枪扫不到镜片码怎么办？**
A: 确认条形码清晰无损坏，扫码枪设置为 Code128 格式。

### 发货相关

**Q: 快递单号怎么生成的？**
A: 点击「确认发货」后系统自动生成，格式为 `{快递公司代码}{12位数字}`。

**Q: 已发货的订单可以退回吗？**
A: 不可以。已发货是终态，如有问题请联系客服处理。

### 验真相关

**Q: 扫码显示「未找到记录」是什么原因？**
A: 可能原因：①镜片码未在系统登记 ②镜片码输入错误 ③该镜片非正品。请联系授权销售商确认。

**Q: 验真页面显示的处方信息不对怎么办？**
A: 请联系代理商核实订单信息，如确认有误可退回重新处理。
