# 仓位系统设计方案

> 2026-05-12

## 目标

按收货地址聚合发货，标签印仓位号，配货人员扫码分拣，通行单按仓位分组。

---

## 完整流程

```
1. 助理打开 labels-print 页面，筛选待发货订单
2. 点击"导出 Excel"
3. 系统按收货地址分组 → 分配仓位号（A1, A2, A3...）→ Excel 加「仓位列」
4. Excel 导入打印机软件 → 标签打印（含仓位号）
5. 配货人员看标签上的仓位号 → 放入对应仓位
6. 助理点击"生成通行单" → 按仓位分组 → 每仓位一张通行单
7. 整仓打包、通行单随箱、交接快递
```

---

## 第一阶段：仓位分配 + 通行单

### 仓位分配逻辑

- 每次导出 Excel 时动态分配，不预维护
- 按收货地址归一化（去空格、标点）分组
- 同地址 → 同仓位号
- 编号从 A1 开始，按地址首次出现顺序递增
- 不跨天累积，每次导出重新分配

### 改动点

| 文件 | 改动 |
|------|------|
| `server.js` | Excel 导出端点：加地址分组 + 仓位分配逻辑，输出加「仓位」列 |
| `server.js` | slip-batch 端点：分组键从地址改仓位 |
| `lib/templates.js` | slipHTML() 加 `binCode` 参数，meta 区显示仓位 |
| `server.js` | slipHTML 调用处传 binCode |
| `shared/tables.js` | 加 `bin_map` 表 ID（备用） |

### Excel 输出格式

```
序号 | 顾客姓名 | 产品型号 | 眼别 | 球镜 | 柱镜 | 轴位 | 镜片码 | 二维码 | 日期 | 仓位
```

### 仓位编号规则

- 每次导出重新分配（不跨天累积）
- 同地址一定同编号
- 不同批次编号可能不同（同批标签内一致，不影响）

## 第二阶段：地址库校验

### 目标

用 195 个历史地址作为主数据，下单时校验，减少地址差错。

### 方案

1. 将 195 个地址导入 customer 表（`收货地址` 字段）
2. 下单页输入地址时，模糊匹配已有地址 → 自动补全
3. 完全不匹配 → 提示"新地址，请确认"
4. 助理可在 Bitable 维护地址库（增删改）

### 改动点

| 文件 | 改动 |
|------|------|
| `public/order.html` | 地址输入框加模糊匹配下拉（调 API 查 customer 表地址） |
| `server.js` | 新增 `/api/agent/addresses?t=xxx` 端点，返回该代理商历史地址列表 |
| Bitable | 手工导入 195 个地址到 customer 表 |

### 校验流程

```
用户输入"北京市海淀" → 匹配到 5 条历史地址 → 下拉展示
用户选择 → 自动填充完整地址
用户输入全新地址 → 提示"新地址，请确认后提交"
```
