## 一、签收功能测试

### 操作步骤

1. 打开标签打印页：`https://lab.gaushclear.com/labels-print?admin=GaushOrderMock`
2. 在筛选栏选择状态为「已发货」
3. 找一个有快递单号的订单
4. 点击该行最右侧的「确认签收」按钮（绿色勾号 ✅）

### 验证点

- [ ] 状态从「已发货」变为「已签收」
- [ ] 该行显示绿色文字「✓ 已签收」
- [ ] 不再有操作按钮（不可退回）

## 二、仓位自动赋码测试

### 操作步骤

1. 打开标签打印页：`https://lab.gaushclear.com/labels-print?admin=GaushOrderMock`
2. 在筛选栏选择状态为「打标签」
3. 观察表格中的「仓位」列（紫色高亮显示）

### 验证点

- [ ] 每行都有仓位编号（不是「—」）
- [ ] 不同收货地址的订单，仓位号不同
- [ ] 相同收货地址的订单，仓位号相同
- [ ] 仓位编号格式：A1/A2/B1/B2/C1/C2/D1/D2（区域编码）或 T-001/T-002（临时编码）

## 三、标签SKU条码测试

### 操作步骤

1. 打开标签打印页：`https://lab.gaushclear.com/labels-print?admin=GaushOrderMock`
2. 在筛选栏选择状态为「打标签」
3. 选中一个订单（点击行或勾选复选框）
4. 点击工具栏的「打印标签」按钮
5. 在弹出的标签预览页面中，查看左下角的条形码

### 验证点

- [ ] 条形码存在且可扫描
- [ ] 条形码下方有文字说明
- [ ] 格式为：`{型号缩写}-{SPH×100}-{CYL×100}`

### 条码格式说明

```
TKAP-250-075
│    │    │
│    │    └── 柱镜 CYL = -0.75 × 100 = 075
│    └─────── 球镜 SPH = -2.50 × 100 = 250
└──────────── 型号缩写：时空之眼PRO = TKAP
```

### 型号缩写对照表

| 产品 | 缩写 |
|------|------|
| Ultra双效 | ULT |
| D8 | D8 |
| 时空之眼A | TKAA |
| 时空之眼B | TKAB |
| 时空之眼PRO | TKAP |
| 时空之眼MAX | TKAM |
| 小旋风 | XFJ |

## 四、完整流程测试（可选）

如果需要测试完整闭环，按以下步骤操作：

### 4.1 代理商下单

1. 打开：`https://lab.gaushclear.com/?t=AG-002-zxkmgoryb6nprmv6`
2. 选择产品（如时空之眼PRO）
3. 填写顾客信息和度数
4. 收货地址填「山西省运城市盐湖区运城眼科医院」
5. 点击提交

### 4.2 等待同步

- 草稿需要约 3 分钟才能同步到系统
- 可以在追踪页查看订单状态

### 4.3 助理确认

1. 打开标签打印页，筛选状态「已下单」
2. 找到刚提交的订单
3. 选中订单，点击「确认」
4. 选择库存状态：「有库存」（走快路径）或「无库存」
5. 等待 5 秒，刷新页面

### 4.4 检查仓位

- 订单状态应变为「打标签」
- 仓位列应显示仓位编号

### 4.5 打印标签

1. 选中订单，点击「打印标签」
2. 检查标签左下角条码格式

### 4.6 发货

1. 点击「发货」按钮
2. 选择快递公司
3. 输入快递单号（如 SF1234567890）

### 4.7 签收

1. 点击「确认签收」按钮
2. 验证状态变为「已签收」

### 4.8 消费者验真

1. 复制镜片码（16位，如 D6E42ACDF31A0B94）
2. 打开：`https://lab.gaushclear.com/verify/{镜片码}`
3. 验证显示「正品验证通过」
