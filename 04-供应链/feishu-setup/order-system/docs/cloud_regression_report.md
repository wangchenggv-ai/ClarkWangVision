## 回归发现

### Bug ⑧-2 同名不混 — 未完全修复（严重度 3）

**现象：** 验真页 `/verify/{lensCode}` 显示同名同订单所有客户的镜片码，包括不同处方的镜片。

**复现数据：**
- 订单 `ORD-20260419-9E52647C`，两个客户同名"张伟"
- 张伟①：Ultra双效，右眼 SPH=-1.00/CYL=-0.25/AXIS=180
- 张伟②：D8，右眼 SPH=-2.00/CYL=-0.75/AXIS=90
- 验真 `4A5DB0D3849F7E56`（张伟① Ultra双效 左眼）时，页面显示 4 个镜片码

**根因：** `server.js:1828` 验真端点按 `srcCustomer`（客户名）过滤镜片记录。同名客户无法区分，导致混入。

```
// 当前代码
const sameCustomerLens = allLens.filter(r =>
  (r.fields["顾客姓名"] || "") === srcCustomer
);
```

**正确做法：** 应直接用镜片码精确匹配，不走客户名二次过滤。验真页只需展示当前镜片码对应的**单眼**信息 + 同一副（同客户同 SKU）的另一眼，而非同名所有镜片。

**影响范围：** 仅影响同名同订单不同处方的验真场景（实际业务中概率低）。
