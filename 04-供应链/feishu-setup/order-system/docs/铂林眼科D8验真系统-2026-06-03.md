# 铂林眼科 D8 独立验真系统

> 创建：2026-06-03 | 状态：已生成待部署

---

## 一、背景

铂林眼科是 D8 产品的大客户，需要一套**独立品牌**的消费者验真页面，与高视高清主品牌完全隔离。早期曾考虑在现有验真系统中用 OEM 多品牌注入方案（`brand-config.js`），但因维护复杂已封存，改用更简单的独立部署方案。

---

## 二、架构

```
消费者扫码
    ↓
QR 码（PNG）→ URL: https://lab.gaushclear.com/bolin/{16位镜片码}
    ↓
server.js 路由 /bolin/:code
    ↓
查 bolin-codes.json（内存）
    ↓
渲染 public/bolin.html（模板占位符替换）
    ↓
消费者看到：铂林眼科品牌 + D8 型号 + SPH/CYL 参数
```

**与现有验真系统完全隔离：**
- URL 命名空间：`/bolin/` vs `/verify/`
- 数据源：`bolin-codes.json`（本地文件）vs Bitable `lens_detail`
- 品牌：铂林眼科绿色主题 vs 高视高清蓝色主题

---

## 三、文件清单

| 文件 | 说明 | 部署 |
|------|------|------|
| `generate-bolin-qr.js` | 一次性生成脚本，本地跑 | 不部署 |
| `bolin-codes.json` | 225个镜片码→度数映射 | 部署到容器 |
| `public/bolin.html` | 铂林验真页模板 | 部署到容器 |
| `server.js` | 新增 `/bolin/:code` 路由 | 已修改，需部署 |
| `bolin-qr/` | 225张QR PNG | 交付铂林眼科 |
| `bolin-manifest.xlsx` | 镜片码+度数清单 | 交付铂林眼科 |

---

## 四、度数矩阵

- **球镜 SPH**：0.00 ~ -6.00，步长 0.25D，共 25 档
- **柱镜 CYL**：0.00 ~ -2.00，步长 0.25D，共 9 档
- **总计**：25 × 9 = **225 种组合**

后续如需扩展度数范围（如 SPH 到 -8.00），重新运行 `generate-bolin-qr.js` 即可，旧镜片码仍有效（`bolin-codes.json` 追加，不替换）。

---

## 五、镜片码规则

- 格式：16 位大写 HEX（`randomBytes(8)`，与主系统一致）
- 生成时机：`generate-bolin-qr.js` 一次性生成
- 一码一度数，永久绑定，不可更改
- 文件名：`D8_S-300_C-075.png`（SPH -3.00，CYL -0.75）

## 六、部署命令

```bash
KEY="密钥/key-gaush-lab.pem"

scp -i "$KEY" public/bolin.html server.js bolin-codes.json root@113.44.175.221:/tmp/
ssh -i "$KEY" root@113.44.175.221 \
  "docker cp /tmp/bolin.html order-app:/app/public/bolin.html && \
   docker cp /tmp/server.js order-app:/app/server.js && \
   docker cp /tmp/bolin-codes.json order-app:/app/bolin-codes.json && \
   docker restart order-app"
```

验真地址示例：`https://lab.gaushclear.com/bolin/D65A58E3B8478507`
