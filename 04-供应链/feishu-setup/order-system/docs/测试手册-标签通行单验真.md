## 一、标签打印

### 步骤

1. 打开管理页：https://lab.gaushclear.com/labels-print?admin=GaushOrderMock
2. 在搜索框输入「张测试」→ 回车
3. 勾选张测试的 2 条记录（OD + OS）
4. 点击「标签预览」按钮
5. 检查预览内容，然后点「导出 Excel」下载

### 验证点

- [ ] 预览显示 2 条标签（OD + OS 各一条）
- [ ] 每条标签包含：顾客姓名、产品型号、眼别、球镜、柱镜、轴位、镜片码
- [ ] 镜片码为 16 位大写字母+数字（如 `A1B2C3D4E5F6G7H8`）
- [ ] Excel 导出格式正确，列名包含：姓名/型号/眼别/球镜/柱镜/轴位/二维码/日期

## 二、随货通行单

### 步骤

1. 在 labels-print 页面，勾选「李测试」的记录
2. 点击「随货同行单」按钮
3. 检查生成的通行单内容

### 验证点

- [ ] 通行单包含客户名「李测试」
- [ ] 产品型号显示「时空之眼PRO」
- [ ] 度数显示正确：OD -5.50/-1.50×90，OS -5.25/-1.25×85
- [ ] 收货地址显示「上海市浦东新区测试路2号」
- [ ] 数量显示 2 副

## 三、二维码扫码验真

### 步骤

1. 在 labels-print 页面，勾选任意一条记录
2. 点击「标签预览」→ 找到「验真码」按钮，点击下载二维码图片
3. 用手机微信扫描该二维码

### 验证点

- [ ] 扫码后跳转到验真页面（域名 lab.gaushclear.com）
- [ ] 页面显示镜片码（与标签上一致）
- [ ] 页面显示产品型号（与下单一致）
- [ ] 页面显示顾客姓名（与下单一致）
- [ ] 换一条记录的二维码扫码，结果对应正确（不张冠李戴）

## 四、边界数据检查

### 测试对象：王小测（CYL=0, AXIS=0）

1. 搜索「王小测」→ 勾选 → 标签预览
2. 检查散光和轴位的显示

### 验证点

- [ ] 散光（CYL）显示为空或「—」，**不是**「0」
- [ ] 轴位（AXIS）显示为空或「—」，**不是**「0」
- [ ] 球镜显示「-1.00」

### 测试对象：李测试（数量=2）

1. 搜索「李测试」→ 导出 Excel
2. 检查记录数

### 验证点

- [ ] Excel 中李测试有 2 条记录（OD + OS 各一条）
- [ ] 序号连续（如 1, 2 或 3, 4）
