专用打印电脑配置清单

斑马打印机 ZT410 · 队列拉模式守护进程 · 高视星镜片供应链系统
目标：在专用 Windows 电脑上运行 pull-print.js 守护进程，轮询华为云打印队列，收到任务后通过 TCP 发送 ZPL 到斑马打印机。

一、网络确认

项目要求验证方法
访问华为云HTTPS lab.gaushclear.com 可达浏览器打开 https://lab.gaushclear.com/health，看到 JSON 文字即通
连斑马打印机同一局域网，打印机 IP 已知看打印机面板 → 网络设置 → 记下 IP 地址
打印机 TCP 端口9100 端口开放telnet 打印机IP 9100 能连上即通

二、安装 Node.js

  1. 打开浏览器访问 https://nodejs.org
  2. 下载 LTS 版本（v20 或 v22，不要 v18 以下）
  3. 安装时一路默认，勾选 "Add to PATH"
  4. 验证：打开 PowerShell（或 CMD），输入：
    node -v
    应显示 v20.x.x 或 v22.x.x

三、复制程序文件

从项目目录复制以下 2 个文件 到打印电脑（如 C:\PrintDaemon\）：

文件名说明
pull-print.js守护进程主程序
pull-print-config.json配置文件（服务器地址、打印机 IP 等）

四、修改配置

用记事本打开 pull-print-config.json：

{
  "serverUrl": "https://lab.gaushclear.com",
  "adminToken": "GaushOrderMock",
  "pollMs": 2000,
  "printerHost": "192.168.0.208",
  "printerPort": 9100,
  "timeoutMs": 5000,
  "maxRetries": 3
}
字段改什么说明
printerHost斑马打印机实际 IP从打印机面板网络设置查
printerPort一般不用改默认 9100 是斑马标准端口
serverUrl不用改指向华为云服务器
adminToken不用改管理后台认证密码

五、启动守护进程

  1. 打开 PowerShell，进入程序目录： 
    cd C:\PrintDaemon
  2. 运行守护进程： 
    node pull-print.js
  3. 看到以下输出即启动成功： 
    [2026/4/23 xx:xx:xx] ℹ pull-print 守护进程启动
[2026/4/23 xx:xx:xx] ℹ 服务器: https://lab.gaushclear.com
[2026/4/23 xx:xx:xx] ℹ 打印机: 192.168.0.208:9100
[2026/4/23 xx:xx:xx] ℹ 轮询间隔: 2000ms
[2026/4/23 xx:xx:xx] ℹ 按 Ctrl+C 退出
注意：保持这个 PowerShell 窗口不要关闭，守护进程一直在轮询等待打印任务。

六、验证连通性

在守护进程运行的状态下，用 另一台电脑 的浏览器打开管理后台：

https://lab.gaushclear.com/labels?admin=GaushOrderMock
  1. 选一个"生产中"的订单，点 🖨 按钮
  2. 回到打印电脑的 PowerShell 窗口，应看到： 
    ℹ 收到 2 个打印任务
✓ 标签已打印: ORD-xxx 张三 右眼 [9A01...]
✓ 标签已打印: ORD-xxx 张三 左眼 [C0CD...]
  3. 斑马打印机应出两张标签

七、常见问题排查

现象排查方法
守护进程报 TCP 失败检查打印机 IP 是否正确，网线是否插好
守护进程报 HTTP 401检查配置文件中 adminToken 是否正确
守护进程报连不上服务器检查网络能否访问 lab.gaushclear.com
等很久没反应正常——队列为空时静默等待，从管理后台触发一个打印任务
打印机出标签但内容空白ZPL 解析问题，联系 Clark 检查
node 命令找不到Node.js 安装时没勾 "Add to PATH"，重新安装

八、下午测试前确认清单

  • Node.js 已安装，PowerShell 中 node -v 正常显示版本号
  • pull-print.js 和 pull-print-config.json 已复制到 C:\PrintDaemon\
  • printerHost 已改为斑马打印机实际 IP
  • 浏览器能打开 https://lab.gaushclear.com/health 看到 JSON
  • telnet 打印机IP 9100 能连上
  • node pull-print.js 启动成功，看到 "守护进程启动" 日志
