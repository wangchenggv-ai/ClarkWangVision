# 标签 Excel 导出 — 操作手册

> 更新：2026-04-28

---

## 功能说明

标签打印页面新增「导出Excel」功能，可将订单的镜片数据导出为 Excel 文件，供其他打印机系统识别和使用。

导出的 Excel 格式与现有标签数据库模板完全一致，可直接导入其他标签打印机软件。

---

## Excel 格式

| 列名 | 说明 | 示例 |
|------|------|------|
| 姓名 | 顾客姓名 | 张三 |
| 型号 | 产品型号 | 时空之眼A |
| 眼别 | 右眼/左眼 | 右眼 |

| 二维码 | 验真链接 | https://lab.gaushclear.com/verify/F1024... |
| 日期 | 订单创建日期 | 2026-04-28 |

## 操作步骤

### 一、批量导出（多订单）

1. 打开 **标签打印 & 发货中心** 页面
2. 使用筛选栏找到目标订单（可按状态/代理商/型号/日期筛选）
3. **勾选** 需要导出的订单（支持全选）
4. 点击操作栏的 **「导出Excel」** 按钮
5. 浏览器自动下载 Excel 文件

### 二、单眼导出（单个订单）

1. 打开 **标签打印 & 发货中心** 页面
2. 在订单列表中找到目标订单
3. 点击该行操作列的 **紫色导出按钮**（图标：）
4. 浏览器自动下载该订单的 Excel 文件

---

## 注意事项

- 只有**已确认**（生成镜片码）的订单才能导出
- 导出的 Excel 按顾客姓名排序，同一顾客双眼在一起
- 二维码链接指向验真页面：`https://lab.gaushclear.com/verify/{镜片码}`
- 批量导出时，多个订单的数据合并到一个 Excel 文件中

## 常见问题

**Q: 导出的 Excel 是空的？**
A: 检查订单是否已确认（状态为"生产中"或"打标签"或"已发货"）。未确认的订单没有镜片码，无法导出。

**Q: 二维码扫出来是什么？**
A: 扫码后会跳转到验真页面，显示该镜片的处方信息和真伪验证结果。

**Q: 可以只导出某一只眼吗？**
A: 可以。点击该行的紫色导出按钮，会导出该订单该顾客的全部镜片（通常是一对双眼）。如需更精细筛选，可先在筛选栏过滤。
