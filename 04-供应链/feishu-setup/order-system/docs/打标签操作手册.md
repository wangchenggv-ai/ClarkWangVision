# 打标签操作手册

> 适用对象：助理/工厂操作员 | 更新日期：2026-04-28

---

## 一、两个页面分清楚

| 页面 | 地址 | 用途 |
|------|------|------|
| **订单管理页** | `{域名}/orders?admin={密码}` | 看所有订单、确认下单、打印标签、发货、退回 |
| **标签打印页** | `{域名}/labels-print?admin={密码}` | 扫码枪扫描镜片码，自动打标签+入打印队列 |

**一句话：扫码用"标签打印页"，打印和发货用"订单管理页"。**

---

## 二、完整流程

```
工厂生产完 → 助理扫码打标签 → 打印标签贴镜片盒 → 发货给代理商
```

---

## 三、场景一：单副镜片操作

### Step 1 — 扫码打标签

1. 打开**标签打印页**（labels-print）
2. 页面顶部扫码栏，用扫码枪对准镜片盒上的条形码扫描
3. 扫码成功：绿色提示 `✓ 镜片码 → 订单号 打标签`
4. 下方表格自动刷新，该订单出现在列表中，状态为"打标签"

> 手动输入：如果没有扫码枪，在输入框手动输入16位镜片码（如 `019C79979C444732`），按回车。

### Step 2 — 打印标签

1. 打开**订单管理页**（orders）
2. 顶部筛选栏，状态选"打标签"
3. 勾选刚扫码的订单
4. 点击操作栏 **"斑马打印"** 按钮
5. 弹窗确认，点"确定"
6. 提示"打印入队完成：成功 1 项"
7. 标签自动发送到打印电脑的斑马打印机

### Step 3 — 确认发货

1. 在**订单管理页**，保持订单勾选状态
2. 点击操作栏 **"确认发货"** 按钮
3. 弹窗中选择快递公司（顺丰/75快递/韵达/京东）
4. 点"确定"
5. 提示"发货完成：成功 1 项"
6. 订单状态变为"已发货"，自动生成快递单号

## 四、场景二：多副镜片批量操作

> 适用情况：同一批次多副镜片，一起扫码、一起打印、一起发货。

### Step 1 — 逐个扫码

1. 打开**标签打印页**
2. 依次扫描每个镜片码（每扫一个，表格自动刷新）
3. 全部扫完后，表格显示所有"打标签"状态的订单

### Step 2 — 批量打印

1. 打开**订单管理页**
2. 状态筛选选"打标签"
3. 点 **"全选"** 复选框
4. 点击 **"斑马打印"**
5. 确认弹窗显示"N 项"，点"确定"
6. 所有标签按顺序入队打印

### Step 3 — 批量发货

1. 保持全选状态
2. 点击 **"确认发货"**
3. 选择快递公司（本批统一一个快递）
4. 点"确定"
5. 全部订单变为"已发货"，每个订单生成独立快递单号

## 五、常见问题

| 问题 | 原因 | 解决办法 |
|------|------|----------|
| 扫码后没反应 | 输入框没聚焦 | 点一下顶部扫码栏的输入框，再扫 |
| 提示"未找到镜片码" | 镜片码不正确或订单未确认 | 检查镜片码是否正确，联系助理确认订单 |
| 提示"已打印过" | 该码之前已扫过 | 正常现象，标签已重新入队，不影响使用 |
| 斑马打印按钮没反应 | 没有勾选"打标签"状态的订单 | 先筛选"打标签"状态，再勾选订单 |
| 提示"没有打标签状态的" | 选了其他状态的订单 | 只勾选"打标签"状态的订单 |
| 打印机不出标签 | 打印电脑/打印机未开机 | 检查打印电脑和斑马打印机是否开机 |

## 六、每日操作检查清单

开始工作前：
- [ ] 打印电脑（192.168.0.110）已开机，Chrome 已打开
- [ ] 斑马 ZD220 打印机已开机（绿灯常亮）
- [ ] 标签纸已装好（40mm × 30mm 热敏纸）
- [ ] 登录系统，确认页面正常显示

结束工作前：
- [ ] 所有"打标签"订单已处理完（打印+发货）
- [ ] 打印机关闭
- [ ] 打印电脑关闭
