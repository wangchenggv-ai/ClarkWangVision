# Admin 控制中心 — 快速上手指南

> 最后更新：2026-04-22 | 访问地址：`/control?admin=<TOKEN>`

## 一、这个 UI 是什么

**一句话：** 不改代码，通过网页管理 14 条业务规则、监控系统状态、手动触发规则、AI 咨询。

```
┌─────────────────────────────────────────────────────────────┐
│  控制中心 = 业务规则的遥控器 + 系统的仪表盘 + AI 参谋       │
├─────────────┬─────────────┬─────────────────────────────────┤
│  Tab1 仪表盘 │  Tab2 规则   │  Tab3 数据流                    │
│  看数字      │  调参数      │  看链路                         │
│  找风险      │  跑规则      │                                 │
│             │  问 AI       │                                 │
└─────────────┴─────────────┴─────────────────────────────────┘
```

## 二、整体架构

```
浏览器 (control.html)
  │
  ├── GET  /api/admin/rules          ─→  读 rules_config.json + RULE_MANIFEST
  ├── POST /api/admin/rules          ─→  写 rules_config.json（单个参数）
  ├── POST /api/admin/execute-rule   ─→  spawn('node automations.js ruleN')
  ├── GET  /api/admin/dashboard      ─→  聚合飞书多表数据（2min 缓存）
  └── POST /api/admin/ai-chat        ─→  callMiMo()，内置全系统知识
  │
  ▼
rules_config.json          ← 参数存储（JSON 文件，非数据库）
automations.js             ← 规则引擎（14 条规则，飞书读写）
server.js                  ← 主服务，承载所有 API + 静态页
```

```
│ [rule11] [rule12]                      │  ├─ AI 助手 ──────────┤
│ [rule13] [rule14]                      │  │ [缺货分析][调参建议] │
│    ↑ 双列（有参数）                     │  │ [对话窗口]          │
├─ ━━━ 生产运营 3条规则 ━━━ ─────────────┤  │ [输入框] [发送]     │
│ [rule7]  [rule8]  [rule9]             │  ├─────────────────────┤
│                                        │  │ [刷新] [全部保存]   │
└────────────────────────────────────────┘  └─────────────────────┘
```

**修改参数的操作：**
1. 点击有参数的规则卡片（双列大卡片）
2. 直接改输入框里的数字
3. 点"保存"（单条）或"全部保存"（批量）
4. 参数立即写入 `rules_config.json`，下次执行规则即生效

**颜色含义：**
- 蓝色 = 订单处理（rule1/2/3/6）
- 绿色 = 库存管理（rule4/5/10/11/12/13/14）
- 橙色 = 生产运营（rule7/8/9）

## 四、14 条规则速查

### 订单处理（蓝色）

| 规则 | 名称 | 可调参数 | 说明 |
|------|------|---------|------|
| rule1 | 订单自动分配 | 现货交期(天)、定制交期(天)、最大下单量 | 新订单查库存写交期 |
| rule2 | 库存预警 | 紧急阈值(倍) | 库存低于阈值告警 |
| rule3 | 模芯寿命预警 | 紧急剩余(次)、预警阈值(次) | 模芯寿命不足告警 |
| rule6 | 订单超期预警 | 告警小时数 | 超时未处理自动告警 |

### 库存管理（绿色）

| 规则 | 名称 | 可调参数 | 说明 |
|------|------|---------|------|
| rule4 | 销售预测→排产 | 夏季/开学/春节系数 | 周预测+季节系数排产 |
| rule5 | 毛坯库存预警 | 安全倍数、最低库存 | 毛坯低于安全线告警 |
| rule10 | 寄售到期预警 | 无（60天黄/90天红） | 寄售库存到期预警 |
| rule11 | 月度对账单 | 无 | 每月1-3日自动生成 |
| rule12 | 度数级库存预警 | 无 | 当前库存<安全库存告警 |
| rule13 | 度数级自动排产 | 生产周期(天)、补货倍数、最小批量、自动确认 | 缺口→工单→分配车房 |
| rule14 | 度数级库存回补 | 自动完成(开关) | 到期/完成→库存回补 |

### 生产运营（橙色）

| 规则 | 名称 | 可调参数 | 说明 |
|------|------|---------|------|
| rule7 | 采购自动触发 | 模具/毛坯交期(天)、再订点、补货目标、最小批量 | 低于安全线自动下单 |
| rule8 | 排产分配车房 | 专长加成 | 按产能+专长分配 |
| rule9 | 模芯使用累加 | 无 | 完工后累加模芯使用量 |
