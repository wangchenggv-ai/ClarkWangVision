# 对账单系统设计方案

> 2026-05-12

## 目标

系统通过顺丰签收数据得知订单已签收，导入对账单后自动匹配，生成含发货日期+签收日期的对账明细。

---

## 完整流程

```
1. 订单发货 → 快递单号写入订单表
2. 顺丰后台导出签收明细 Excel（快递单号 + 签收时间）
3. 助理上传 Excel 到系统
4. 系统按快递单号匹配订单 → 写入签收时间 → 状态改为"已签收"
5. 助理按代理商+时间段导出对账单
6. 对账单含：发货日期、签收日期、镜片明细、交期天数
```

---

## 数据模型

### 订单表新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 签收时间 | 日期时间 | 顺丰签收时间，导入时写入 |

### 状态机

```
已发货 → 已签收（终态）
```

- "已签收"恢复为有效状态（之前被废弃，现重新启用）
- 已签收不可退回
- 签收时间由导入写入，不由系统自动推断

## 功能一：导入签收数据

### 入口

labels-print.html 或独立管理页，"导入签收数据"按钮

### 顺丰签收明细 Excel 格式

顺丰后台导出的签收明细通常包含：

| 列名 | 说明 | 匹配字段 |
|------|------|----------|
| 运单号 | 快递单号 | 订单表.快递单号 |
| 签收时间 | 签收日期时间 | 写入订单表.签收时间 |
| 签收人 | 签收人姓名 | 可选，备注用 |

### 导入逻辑

```
1. 解析 Excel，提取（快递单号, 签收时间）对
2. 遍历每条记录：
   a. 按快递单号查订单表（精确匹配）
   b. 找到订单 → 写入签收时间
   c. 更新订单状态为"已签收"
   d. 同步更新镜片明细表状态
3. 返回导入结果：
   - 成功 N 条
   - 未匹配 M 条（快递单号在系统中不存在）
   - 已签收跳过 K 条（之前已导入过）
```

### 幂等性

- 同一快递单号重复导入 → 跳过（已签收的不再处理）
- 快递单号不存在 → 记录到未匹配列表，不报错

### API 端点

```
POST /api/admin/import-delivery
Content-Type: multipart/form-data

参数：
  file: Excel 文件

返回：
  {
    ok: true,
    imported: 50,     // 成功导入
    skipped: 3,       // 已签收跳过
    unmatched: ["SF1234567890", ...],  // 未匹配的快递单号
    errors: []        // 解析错误
  }
```

## 功能二：对账单导出增强

### 现有端点增强

`GET /api/admin/statement` 现有输出列：

```
订单编号 | 客户姓名 | 产品型号 | 眼别 | 球镜 | 柱镜 | 轴位 | 镜片码 | 数量 | 发货日期 | 物流公司 | 快递单号 | 收货地址
```

新增列：

```
... | 签收日期 | 签收状态 | 交期天数
```

| 新增列 | 说明 |
|--------|------|
| 签收日期 | 签收时间格式化为 YYYY-MM-DD |
| 签收状态 | "已签收" 或 "未签收" |
| 交期天数 | 发货日期到签收日期的天数差 |

### 筛选增强

新增筛选参数：

| 参数 | 说明 |
|------|------|
| status | "all"（默认）/ "signed"（仅已签收）/ "unsigned"（仅未签收） |

## 状态机变化

### 现有状态

```
已下单 → 待处理 → 生产中 → 打标签 → 已发货（终态）
```

### 新增状态

```
已下单 → 待处理 → 生产中 → 打标签 → 已发货 → 已签收（终态）
```

- 已签收是新的终态
- 从"已发货"到"已签收"由导入触发
- 已签收不可退回

## 对账场景示例

### 场景：月度对账

```
1. 月初，助理从顺丰后台导出上月签收明细
2. 上传到系统 → 50 条导入成功，2 条未匹配
3. 导出对账单（代理商：北京澳美雅博，时间：2026-04）
4. 对账单显示：
   - 张三 | 时空之眼PRO | R | -2.75 | 2026-04-05发货 | 2026-04-08签收 | 3天
   - 李四 | D8 | L | -1.50 | 2026-04-10发货 | 未签收 | —
5. 助理核对后与代理商结算
```
