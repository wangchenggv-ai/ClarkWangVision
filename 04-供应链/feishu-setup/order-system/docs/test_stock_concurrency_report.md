## 关键改动

- `withLock()` per-key 异步锁 — 序列化同一 SKU/SPH/CYL 的并发扣减
- `deductStockDetail` 锁内 fresh read 单条记录（~200ms）
- `/api/submit` 四阶段：预检(409) → 写订单 → 扣库存(失败标记人工)
- `clientRequestId` 幂等保护（10min TTL）
- 前端 409 库存冲突弹窗
