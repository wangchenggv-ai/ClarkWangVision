# 测试报告：订单系统 2026-05-29

## 测试背景

2026-05-27 起，所有代理商订单在追踪页显示"提交失败，请联系客服"。
本次测试目标：验证 Bug 修复完整有效，并全流程回归。

---

## 一、问题根因 & 修复摘要

### 根因 1：写入不存在的字段 `"终端客户"`

5.26 新增代码向 Bitable 写入 `"终端客户"` 字段，但该字段已于 5.19 重命名为 `"终端门店"`。
飞书 API 返回 `FieldNameNotFound (code 1254045)`，导致 `batchCreateRecords` 返回 null，
草稿重试 10 次后置为 `syncFailed=true`，代理商看到"提交失败"。

**修复**：`server.js` `processPendingDrafts()` 删除 `"终端客户"` 字段写入。

### 根因 2：写入不存在的字段 `"关联门店"`

5.26 同时新增 `"关联门店": [terminalCustomer.recordId]` 写入，
订单主表从未建过此字段，测试环境中该字段有值（store_master 已配置），
触发同样的 FieldNameNotFound。

**修复**：删除 `"关联门店"` 整行写入。

### 附：测试 Bitable 字段名同步修正

5.19 生产 Bitable 字段改名（`终端客户→终端门店`、`客户名称→门店名称`）
未同步到测试 Bitable，导致测试环境也无法正常写入。
通过飞书 API PUT `/fields/{field_id}` 完成修正。

### 优化：去掉草稿等待窗口

原 `DRAFT_AGE_MIN = 3min`（代理商编辑窗口），现在只有内部人员下单，无需等待。
修改为：
```
DRAFT_SYNC_INTERVAL = 30s   （原 2min）
DRAFT_AGE_MIN       = 0     （原 3min）
```
效果：提交后最长 30 秒内同步飞书。
