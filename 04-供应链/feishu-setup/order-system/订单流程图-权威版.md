## 二、各状态详细说明

### 状态1：已下单

| 项目 | 内容 |
|------|------|
| **进入条件** | 代理商在门户点击「提交订单」 |
| **系统动作** | POST /api/submit → 生成订单编号(ORD-YYYYMMDD-XXXXXX) → 写订单主表(一患者一行) → 写镜片明细表占位行(一眼一行，此时无镜片码) |
| **操作栏** | 待确认🔵（蓝色按钮） |
| **代理商可见** | 可在追踪页看到"已下单"状态，此时仍可修改参数 |
| **退回** | 不适用（初始状态） |
| **超期预警** | >3天未确认触发告警 |

### 状态2：待处理（仅无库存路径）

| 项目 | 内容 |
|------|------|
| **进入条件** | 助理点击"待确认"且订单库存状态="无库存" |
| **系统动作** | POST /api/admin/confirm → 读取记录中的"库存状态"字段 → 生成镜片码写入镜片明细表 → 订单主表状态="待处理" → 工作流推进到"confirmed" |
| **操作栏** | 已确认🟣（紫色，只读显示）+ 退回按钮 |
| **退回** | 待处理 → 已下单（清空镜片码） |
| **超期预警** | >5天未导出触发告警 |

### 状态3：生产中（仅无库存路径）

| 项目 | 内容 |
|------|------|
| **进入条件** | 助理在管理页筛选订单后点击「导出Excel」，执行下载即自动触发 |
| **系统动作** | POST /api/admin/batch-zip 或导出端点 → 下载Excel文件 → 自动将"待处理"订单状态改为"生产中" → 同步镜片明细表 → 工作流推进到"producing" |
| **Excel内容** | 订单编号、顾客姓名、产品型号、SPH/CYL/AXIS、镜片码、收货地址、备注 |
| **筛选条件** | 时间/有无库存/是否装配/供应商/订单状态（支持全选） |
| **操作栏** | ⚙️ 生产中 + 退回按钮 |
| **退回** | 生产中 → 待处理 |
| **超期预警** | >7天未发货触发告警 |

### 状态4：打标签（配货阶段）

| 项目 | 内容 |
|------|------|
| **进入条件A** | 有库存：助理点"待确认"后直接进入（跳过待处理+生产中） |
| **进入条件B** | 无库存外发：工厂加工完成回来，扫码镜片码触发自动打印标签 |
| **系统动作** | 订单状态="打标签"，工作流推进到"labeled" |
| **打印标签** | ZPL标签：Code128条形码 + QR验真码 + 处方数据；系统限打1次，重复打印有提醒 |
| **配货操作** | 1. 标签放托盘 → 2. 按标签参数配货 → 3. 换包装贴标签 → 4. 扫包装袋条形码 → 5. 系统识别发货地址 → 6. 分配仓位（罗马数字编号，同地址同仓位） → 7. 装配品进0号仓位 |
| **操作栏** | 🏷 打标签 + 退回按钮 |
| **退回** | 打标签 → 已下单（无论有库存/无库存路径，统一退到已下单，同时清空镜片码） |

### 状态5：已发货（终态）

| 项目 | 内容 |
|------|------|
| **进入条件** | 输入快递单号（从打标签或生产中均可触发） |
| **系统动作** | POST /api/admin/ship → 写入物流公司/快递单号/发货时间 → 状态="已发货" → 工作流推进到"shipped" → 发飞书发货通知卡片 |
| **可发货的前置状态** | 打标签（主路径：现货配货完成）、生产中（供应商直发路径） |
| **发货时扣库存** | 若库存状态="有库存"，发货时从stock_detail扣减1片，写出库流水 |
| **随货同行单** | 同一发货地址1张，打包发货前打印 |
| **操作栏** | 🚚 已发货（只读，无退回） |

## 三、系统关键规则

### 镜片码（16位大写HEX）

```
生成时机：助理点击"待确认"时（/api/admin/confirm 调用 assignLensCodes()）
生成规则：randomBytes(8).toString('hex').toUpperCase()
存储：写入镜片明细表"镜片码(唯一)"字段，同时汇总写入订单主表"镜片码"字段
幂等：已有镜片码的行自动跳过，不重新生成
铁律：镜片码一旦生成，终生不变，绝不允许回写/重新生成
退回：退回到"已下单"时，清空镜片码（下次确认时重新生成）
```

### QR验真码

```
格式：{SERVER_BASE_URL}/verify/{镜片码}
生成：镜片码生成后异步生成PNG，存入 public/qrcodes/{镜片码}.png
消费者：扫码 → GET /verify/:lensCode → 镜片明细表 → 订单主表 → 显示处方+订单信息
```

### 工作流步骤（叠加在订单状态之上）

```
步骤键：submitted → confirmed → producing → labeled → shipped
对应态：已下单   → 待处理   → 生产中   → 打标签  → 已发货

存储：订单主表"流程步骤"字段（JSON，含每步时间戳）
规则：防跳步、防回退、幂等（advanceWorkflow函数）
```

### 退回规则

```
可退回：已下单、待处理、生产中、打标签
不可退：已发货（终态）
退回映射：
  生产中 → 待处理
  待处理 → 已下单（清空镜片码）
  打标签 → 已下单（清空镜片码，无论来自有库存还是无库存路径）
```

## 四、三条完整路径时序

### 路径A：有库存（现货）

```
时间轴  角色      动作                        系统状态
──────  ────      ────                        ────────
T+0     代理商    提交订单                     已下单
T+?     助理      选择"有库存" → 点待确认      [打标签]
                  ↳ 系统：赋镜片码             镜片码已生成
T+?     助理      打印标签（扫码/全选）         —
                  ↳ 系统：ZPL入打印队列        标签打印中
T+?     助理      配货 → 扫包装袋 → 分仓位     —
T+?     助理      打随货同行单 → 输快递单号     [已发货]
                  ↳ 系统：扣库存，发飞书通知   终态
```

### 路径B：无库存，外发加工

```
时间轴  角色      动作                         系统状态
──────  ────      ────                         ────────
T+0     代理商    提交订单                      已下单
T+?     助理      选"无库存"+供应商 → 点待确认   [待处理]
                  ↳ 系统：赋镜片码              镜片码已生成
T+?     助理      筛选 → 全选 → 导出Excel       [生产中]
                  ↳ 系统：下载Excel，自动推进   导出触发状态变更
T+?     供应商    生产镜片（5-10天）             —
T+?     助理      收货 → 扫码镜片码打印标签      [打标签]
                  ↳ 系统：打印ZPL              配货中
T+?     助理      配货 → 分仓 → 输快递单号       [已发货]
                  ↳ 系统：发飞书通知            终态
```

### 路径C：无库存，供应商直发

```
时间轴  角色      动作                         系统状态
──────  ────      ────                         ────────
T+0     代理商    提交订单                      已下单
T+?     助理      选"无库存"+供应商 → 点待确认   [待处理]
T+?     助理      导出Excel → 发给供应商         [生产中]
T+?     供应商    直接发货，提供快递单号         —
T+?     助理      录入快递单号                  [已发货]
                  ↳ 系统：跳过打标签直接发货    终态
```

## 五、管理界面操作对照

### labels.html（助理管理页）

| 订单状态 | 操作栏显示 | 可用批量操作 | 退回 |
|---------|-----------|------------|------|
| 已下单 | 待确认🔵 | 确认下单 | — |

### order.html（代理商门户）

| 功能 | 说明 |
|------|------|
| 提交订单 | 输入患者信息+处方 → 提交 → 状态变"已下单" |
| Excel导入 | 上传Excel → 解析 → 批量提交 |
| 追踪页 | 只读查看订单状态（已下单/待处理/生产中/打标签/已发货） |

## 六、关键API端点

| 方法 | 路径 | 功能 | 状态变化 |
|------|------|------|---------|
| POST | /api/submit | 代理商提交订单 | → 已下单 |
| POST | /api/admin/confirm | 助理确认（赋镜片码） | 已下单 → 待处理 / 打标签 |
| POST | /api/admin/revert | 退回上一步 | 逐级退回 |
| GET | /api/admin/batch-zip | 导出工厂包（触发生产中） | 待处理 → 生产中 |
| POST | /api/admin/ship | 确认发货 | 生产中/打标签 → 已发货 |
| POST | /api/admin/print-queue | 打印标签入队 | — |
| GET | /verify/:lensCode | 消费者验真 | — |

## 七、Bitable 数据模型（核心两表）

### 订单主表（一患者一行）

```
订单编号（主键）：ORD-YYYYMMDD-XXXXXX
订单状态（单选）：已下单 / 待处理 / 生产中 / 打标签 / 已发货
库存状态（单选）：有库存 / 无库存
供应商厂家（单选）：高清 / 圣普 / 九次方 / 五彩 / 欧陆
镜片码（文本）：该订单所有镜片码，逗号分隔
流程步骤（文本）：JSON，记录每步完成时间戳
```

### 镜片明细表（一眼一行）

```
镜片码(唯一)（文本，主键）：16位HEX
订单编号（文本）：关联主表
眼别（单选）：右眼 / 左眼
球镜SPH / 柱镜CYL / 轴位AXIS（数字）：处方参数
订单状态（单选）：与主表同步
```

## 八、废弃状态说明

| 废弃状态 | 废弃原因 | 替代 |
|---------|---------|------|
| ~~待签收~~ | 不在权威业务流中，已移除 | 已发货即终态 |
| ~~已签收~~ | 不在权威业务流中，已移除 | 已发货即终态 |

| ~~已打包~~ | 内部工作流步骤，不作为订单状态 | 流程步骤JSON记录 |
