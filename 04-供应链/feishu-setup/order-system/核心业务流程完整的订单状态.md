# 核心业务流程 — 权威定义

> 最后更新：2026-04-27
> 本文件是订单状态机的唯一真相源。代码与此不符，以此为准。

---

## 一、状态总览

```
提交订单 → 已下单 → 待处理 → 生产中 ─┬→ 打标签 → 已发货
                  └→ 打标签 ──────────┘         ↑
                  （有库存快捷路径）    供应商直发 ─┘
```

| 状态 | 含义 | 进入动作 | 操作栏显示 |
|------|------|---------|-----------|
| 提交订单 | 代理商在门户提交 | 代理商按「提交订单」 | — |
| 已下单 | 订单已收到，等待助理确认 | 系统自动 | 待确认🔵（代理商此时仍可修改参数） |
| 待处理 | 无库存，需外发加工，等待导出Excel | 助理点「待确认」（无库存路径） | 已确认🟣 |
| 生产中 | Excel已发给供应商/车房，镜片生产中 | 助理执行导出Excel（自动变更） | — |
| 打标签 | 产品到货配货中（现货或加工回来） | 见下方分支说明 | — |
| 已发货 | 快递已揽件，产品发出 | 输入快递单号 | — |

---

## 二、分支路径详解

### 路径 A：有库存（现货片）
```
已下单 → [点「待确认」+ 赋镜片码] → 打标签 → [输入快递单号] → 已发货
```
- 库存片已是成品，无需生产，确认后直接进入配货打标签
- 现阶段人工判断有无库存；后续关联库存表后自动判断

### 路径 B：无库存，外发加工（自产/车房）
```
已下单 → [点「待确认」+ 赋镜片码] → 待处理
       → [筛选供应商，导出Excel] → 生产中
       → [扫码镜片码，自动打印标签] → 打标签
       → [输入快递单号] → 已发货
```

### 路径 C：无库存，供应商直接发货
```
已下单 → [点「待确认」+ 赋镜片码] → 待处理
       → [筛选供应商，导出Excel] → 生产中
       → [输入快递单号] → 已发货（跳过打标签）
```
- 货在供应商处直接发出，我们不参与贴标签

---

## 三、关键规则

### 镜片码
- **生成时机：点击「待确认」时**，不在提交时生成
- 生成后终生不变，不可回写/重新生成

### 退回功能
- 已下单 / 待处理 / 生产中 均可退回上一步（逐级，不可跨级）
- 打标签、已发货不可退回

### 已废弃状态
- ~~待签收~~、~~已签收~~ — 已从状态机移除，代码中如有需清理

## 四、「待处理」阶段操作细节

筛选条件（多选）：
- 时间范围
- 有无库存
- 是否装配
- 供应商
- 订单状态

操作：筛选完成后可全选，一键导出同类型订单Excel给工厂。执行导出后订单状态自动变为「生产中」。

---

## 五、「打标签」阶段操作细节

**现货（路径A）：** 进入打标签后：
1. 打印标签（系统限定打印1次，重复打印有提醒）
2. 将1副标签放到托盘，根据标签参数配货
3. 按客户名称换包装、贴标签
4. 扫码发货 → 自动识别发货地址 → 分配仓位编号（罗马数字，按扫码顺序，相同地址归同一仓位）
5. 装配品 → 0号仓位；非装配品 → 数字编号仓位

**外发加工回来（路径B）：** 扫描镜片码 → 自动打印标签 → 进入配货流程（同上4-5步）

**供应商直发（路径C）：** 跳过打标签，直接到已发货。

---

## 六、「已发货」阶段

- 在快递单号栏输入单号 → 状态自动从「打标签」或「生产中」更新为「已发货」
- 随货同行单：按仓位装彩盒，同一发货地址1张随货同行单，打包发货
- 供应商发货的：快递单号由供应商提供，录入系统即完成
