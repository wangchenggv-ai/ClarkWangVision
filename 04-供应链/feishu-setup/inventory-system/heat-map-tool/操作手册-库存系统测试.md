## 二、需要填的数据

### 2.1 度数级库存表（最重要）

打开飞书表，每一行是一个 **产品型号 × SPH × CYL** 的库存。

| 字段 | 说明 | 示例 |
|------|------|------|
| SKU编号 | 产品型号，必须和下拉选项一致 | Ultra双效 |
| SPH | 球镜度数（负数或0） | -1.00 |
| CYL | 柱镜度数（负数或0） | -0.50 |
| **当前库存** | **← 填这个**，实际库存片数 | 120 |
| **安全库存** | **← 填这个**，低于此值触发补货建议 | 50 |
| 序列号 | 已自动回填，不用管 | 009 |
| 货位编号 | 已自动回填，不用管 | A-01-2-03-A |
| ABC分类 | 已自动回填，不用管 | A |

**操作步骤：**
1. 打开飞书表链接
2. 找到要修改的行（按SKU编号/SPH/CYL筛选）
3. 直接修改「当前库存」和「安全库存」两个数字
4. 改完自动保存

**提示：** 共 7 个产品 × 225 个度数 = 1575 行。建议先填 Ultra双效 和 D8（最常用的两个SKU）。

### 2.2 SKU地址映射表（已填好，核对即可）

这张表 219 行，已从仓库设计 Excel 导入。核对一下数据是否正确：

| 字段 | 说明 |
|------|------|
| 序列号 | 001-219 |
| SPH/CYL | 度数组合 |
| ABC分类 | A=高频(001-061) / B=中频(062-104) / C=低频(105-219) |
| 货位编号 | 如 A-01-3-01-A |
| 总片数 | 该度数的备库目标总量 |
| 安全库存 | 总片数 × 20% |

## 三、测试新功能

### 3.1 消耗分析

1. 打开库存管理后台
2. 点击「消耗分析」Tab
3. 选择日期范围（默认近7天）
4. 查看：SKU消耗对比表 + 度数热力图

**验证点：**
- 有发货订单的日期范围应该有数据
- 环比趋势箭头正确（↑消耗增加 / ↓消耗减少）
- 热力图颜色越深=消耗越多

### 3.2 生产建议

1. 点击「生产建议」Tab
2. 系统自动计算：安全库存 - 当前库存 = 缺口，缺口 - 在途排产 = 净缺口
3. 勾选要生成排产单的行（可修改建议产量）
4. 点「一键生成排产单」

**验证点：**
- 只有「当前库存 < 安全库存」的行才会出现
- 序列号和货位列显示正确（如 009 / A-01-2-03-A）
- 生成后在「排产管理」Tab 能看到新工单

### 3.3 库存总览

1. 点击「库存总览」Tab
2. 选 SKU 筛选
3. 查看度数矩阵热力图（绿色=充足，黄色=偏低，红色=缺货）

## 四、常见问题

**Q: 生产建议 Tab 显示"暂无补货建议"？**
A: 说明所有度数的当前库存 ≥ 安全库存。先把安全库存填上，再看效果。

**Q: 序列号/货位列显示"--"？**
A: 该行的 SPH/CYL 超出仓库设计范围（SPH < -6 或 CYL < -2），属于定制品，不在备库范围内。

**Q: 填完库存数字后页面没更新？**
A: 库存数据有 2 分钟缓存，等一下再刷新页面。

**Q: 安全库存填多少合适？**
A: 参考「SKU地址映射表」的「安全库存」列（总片数×20%）。例如序列号003（SPH:-1.00 CYL:0）总片数447，安全库存=89。
