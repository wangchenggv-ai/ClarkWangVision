# Ultra 车房库存管理 — 测试指南

## 这是什么？

管理车房镜片库存的工具。每个 SPH/CYL 组合有一个**序列号**（001-219），贴在料盒标签上。出库/入库时只需输入序列号+数量，不需要认识镜片参数。

## 启动方式

**双击 `启动库存工具.bat`**，浏览器自动打开。

首次运行会自动下载 Node.js（约30MB），之后秒启动。需要登录飞书一次（浏览器弹窗授权）。

---

## 五个功能 Tab

### Tab 1: 快速出库（主要使用）

**出库流程**：
1. 从货架拿镜片，看料盒标签上的**序列号**（如 `003`）
2. 在页面输入序列号 → 自动显示 SPH/CYL 和库存量
3. 填写出库数量 → 点击"确认出库"
4. 完成！库存自动扣减

### Tab 2: 快速入库

**入库流程**：
1. 到货后，看料盒标签上的**序列号**
2. 输入序列号 → 自动显示当前库存
3. 填写入库数量 → 点击"确认入库"
4. 完成！库存自动增加

### Tab 3: 库存热力图

SPH × CYL 矩阵，颜色编码库存量。**左键点击**=出库，**右键点击**=编辑基准库存。

颜色含义：绿=充足(>30)，黄=适中(10-30)，橙=偏低(3-9)，红=紧缺(1-2)，暗红=缺货(0)

### Tab 4: 出库记录

查看所有出库明细，可删除（删除后库存自动回补）。

### Tab 5: 周报导出

按日期+型号筛选，汇总出库数量，导出 CSV 给工厂补货。

## 技术信息

- 飞书 Base：https://gausheyetech.feishu.cn/base/O1Zwbdcnva1kZEsRdgjcuaEZnfc
- 库存表：225 条（25 SPH × 9 CYL）
- 序列号：219 个（按频率排序，A类001-061 / B类062-104 / C类105-219）
- 自动扣减公式：`实际库存 = 当前库存 - SUM(出库明细.数量)`
