## 每日操作

### 出库（最常用）

1. 复制 `每日出库模板.csv`，**按日期命名**：`出库_20260527.csv`

2. 填入当天数据：

| 列名 | 必填 | 格式 | 示例 |
|------|------|------|------|
| SPH | ✅ | 两位小数 | `-3.00` |
| CYL | ✅ | 两位小数，无散光填 `0.00` | `-0.75` |
| 出库数量 | ✅ | 正整数 | `2` |
| 日期 | 可选 | YYYY-MM-DD，省略取今天 | `2026-05-27` |
| 备注 | 可选 | | `张三订单` |

3. 运行脚本：

```bat
python import_stock.py 出库 出库_20260527.csv
```

4. 飞书 SKU库存表当前库存自动更新。

5. **导完即归档**：把文件移入 `归档/` 文件夹，桌面只保留空模板。

> ⚠️ 防重复扣减：同一个文件跑两次库存会扣两次。文件导完后立即归档，不留在桌面。

### 入库

1. 复制 `每日入库模板.csv`，按日期命名：`入库_20260527.csv`
2. 填入数据，运行：

```bat
python import_stock.py 入库 入库_20260527.csv
```

3. 导完归档，同出库规则。

### 少量手工入库（不用脚本）

直接在飞书多维表格 → **入库流水** 表 → 新增一行，填入 SKU、SPH、CYL、入库数量、日期，保存后库存自动更新。

## 常见问题

**Q：同一天多次运行脚本会重复扣库存吗？**  
A：会。防重方法：文件按日期命名（`出库_20260527.csv`），导完立即移入 `归档/` 文件夹，桌面不留已导文件。

**Q：导入后发现数量填错了怎么办？**  
A：在飞书「出库流水」或「入库流水」表中找到对应记录，直接修改数量或删除记录，库存自动重算。不需要重跑脚本。

**Q：能回溯历史库存吗？**  
A：能。入库流水和出库流水都有日期字段，可在飞书筛选查看任意时段的流水。

**Q：SKU在库存表里找不到怎么办？**  
A：脚本会跳过该行并报错，但仍会写入流水。需在SKU库存表手动补录该SKU行后，库存才会自动匹配。
