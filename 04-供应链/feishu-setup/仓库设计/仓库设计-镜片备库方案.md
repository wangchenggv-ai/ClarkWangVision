# 镜片备库仓库设计方案

> 25000片 | 219个SKU | 序列号001-219 | 2026-05-16

---

## 一、设计目标

基于历史订单数据（1-3月）的SPH/CYL参数分级比例，设计一个约11㎡（3.1m×3.5m）的镜片备库仓库，满足：

- **防呆**：员工不需要认识镜片本身，按序列号+货位编号取货即可
- **高效**：高频SKU放在黄金高度层，减少弯腰/踮脚
- **可扩展**：地址编码+货架布局兼容未来AGV/机械臂自动化配货
- **FIFO**：流利式货架前取后补，先进先出

### 5.3 料盒防呆设计

- **颜色区分**：A蓝/B绿/C黄，进错区域一眼看出

- **安全库存线**：料盒内壁标有红色最低库存线（20%处）

```
│     货位: C-08-2-04   数量: 1                   │
│     ████ ████ ████ ████ (条形码)               │
│──────────────────────────────────────────────│
│  路径: A区→C区  预计用时: 3分钟                  │
└──────────────────────────────────────────────┘
```

### 8.2 配货步骤

```
1. 拿配货单 → 看第一行序列号
2. 看颜色 → A区蓝色 / B区绿色 / C区黄色
3. 找到货架号 → 看货架侧面的编号牌
4. 找到层号 → 看层侧面的层号牌
5. 找到位号 → 看料盒正面的序列号
6. 取货 → 扫描料盒二维码确认
7. 按路径顺序继续下一个
```

### 8.3 路径优化规则

配货单按以下顺序排列，减少来回走动：

1. **同货架相邻位**：A-01-3-02 → A-01-3-03（同层相邻）
2. **同货架不同层**：A-01-3-02 → A-01-2-02（同列不同层）
3. **同区不同货架**：A-01 → A-02（按货架号递增）
4. **跨区**：A区 → B区 → C区（按区域顺序）

## 九、防呆机制

### 9.1 五道防线

| 防线 | 机制 | 说明 |
|------|------|------|
| **物理防呆** | 颜色分区 | A蓝/B绿/C黄，进错区域一眼看出 |
| **物理防呆** | 料盒卡槽 | 凸起卡槽嵌入货架，不会推错位 |
| **视觉防呆** | 货位标签 | 每个货位有SPH/CYL标签（大字） |
| **视觉防呆** | 层/列标识 | 每层左侧CYL牌，每列顶部SPH牌 |
| **流程防呆** | 扫码确认 | 取货时扫描料盒二维码=确认取对 |

### 9.2 补货防呆

```
补货流程：
  工厂到货 → 暂存区开箱 → 扫描装箱单
    → 系统显示各SKU应放货位
    → 按货位上架 → 扫码确认上架完成
    → 系统自动更新库存

安全库存：
  - 料盒内壁标有红色最低库存线（容量的20%）
  - 系统每日检查，低于安全库存自动提醒补货
  - 补货点 = 总片数 × 20%
```

### 9.3 盘点机制

| 频率 | 范围 | 方式 |
|------|------|------|
| 每日 | A区1/3（约20个SKU） | 盲盘：扫码报数→系统比对 |
| 每周 | B区全部（43个SKU） | 盲盘 |
| 每月 | C区全部（115个SKU） | 盲盘 |
| 季度 | 全库盘点 | 全员参与 |

## 十、兼容未来自动化

### 10.1 当前→自动化升级路径

| 设计点 | 当前人工 | 未来升级 | 改造成本 |
|--------|---------|---------|---------|
| 地址编码 | 纸质标签 | 二维码/RFID | 低（贴标签即可） |
| 货架间距 | 1.2m主通道 | AGV通行 | 无需改造 |
| 料盒标准 | 三种尺寸统一 | 自动化料盒 | 中（替换料盒） |
| 配货单 | 纸质 | PDA/手机APP | 低（系统改造） |
| 库存管理 | 手工记录 | WMS系统 | 中（系统对接） |
| 指引灯 | 可选安装 | 机械臂视觉 | 中（加装硬件） |

### 10.2 关键原则

1. **地址编码一旦确定就不要改** — 这是自动化的基础
2. **货架通道宽度保留1.2m** — 兼容AGV最小转弯半径
3. **料盒尺寸标准化** — 未来可无缝替换为自动化料盒
4. **所有标签预留二维码位** — 未来扫码枪/PDA可直接读取
