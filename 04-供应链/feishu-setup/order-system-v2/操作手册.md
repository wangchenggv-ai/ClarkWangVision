## ⭐ 一批订单，四步搞定

1. 把代理商订单**整理成标准 Excel**，放进 `inbox/` 文件夹 —— 见【第二步】，最关键
2. 双击 **`1-处理订单.command`** → 打开配货单核对 → 按**回车**确认
3. 仓库按配货单**拣货、核对**实物
4. 核对无误，双击 **`2-扣库存.command`** → 按**回车**

> 全程不用开终端、不用记命令、不用抄批次号。批次号系统自动接力。

## 一、系统在做什么

```
代理商订单 Excel
  └─ 放进 inbox/
       └─ 双击「1-处理订单」
            ├─ 自动匹配 序列号 + 货位 + 镜片码
            ├─ 按库存分流：有货→配货单 / 缺货→排产单
            ├─ 写入飞书（批次汇总表 + 镜片明细表）
            └─ 处理完的 Excel 自动归档到 inbox/done/日期/
       └─ 仓库按配货单拣货核对
            └─ 双击「2-扣库存」→ 扣减库存 + 状态转「已发货」
```

输出在 `output/日期/`：
- `labels.xlsx` —— 配货单（有货，仓库拣货）
- `factory.xlsx` —— 排产单（缺货，工厂生产；有缺货才生成）
- `errors.xlsx` —— 异常记录（有问题才生成）

## 二、第一步：把订单整理成标准 Excel（最关键）

代理商发来的订单**格式五花八门**（表头位置、列名、有没有门店都不同），系统只认**标准模板**。助理要先把订单「翻译」成下面的格式。

### 2.1 文件命名
```
AG-011_20260525.xlsx   ←  代理商编号 + 日期
```
代理商编号 `AG-xxx` 在飞书**代理商表**查。编号必须对，系统靠它认代理商。

### 2.2 标准列（每眼一行，推荐）

| 顾客姓名 | 产品型号 | 眼别 | 球镜SPH | 柱镜CYL | 轴位AXIS | 终端门店 | 联系人 | 联系电话 | 收货地址 | 是否装配 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 王瑾玥 | Ultra双效 | 右眼 | -1.25 | 0.00 |  | 松花路-代理商 | 徐丽冬 | 13263687253 | 哈尔滨… | 否 | 不装配 |
| 王瑾玥 | Ultra双效 | 左眼 | -1.50 | 0.00 |  | 松花路-代理商 | 徐丽冬 | 13263687253 | 哈尔滨… | 否 | 不装配 |

**整理要点：**
- **每只眼一行**（左右眼各一行）。
- **眼别**：右眼 / 左眼（也认 右/左/R/L/OD/OS）。
- **产品型号**：当前序列号支持 `Ultra双效`；其他型号要先在飞书「SKU序列号映射」表登记才能用。
- **柱镜CYL 空白 = 填 0.00**（纯球镜无散光，照填 0.00，不要留空）。
- **终端门店**填飞书门店主数据表里的名称，系统会自动带出收货地址/联系人/电话；门店没登记就手动填后面三列。
- **是否装配**：只发裸片填「否」；要装框填「是」。

### 2.3 真实例子（这次的王瑾玥单）

代理商原件是「高清离焦框架镜订单表格」，与模板差 4 处，助理这样改：

| 原始订单长这样 | 怎么改 |
|---|---|
| 表头夹在客户信息中间（不在第一行）| 重排成第一行就是列标题 |
| 文件名「王瑾玥 17 不装配」无编号 | 改名 `AG-011_20260525.xlsx` |
| 没有门店列，收货地址写在抬头 | 填到「收货地址/联系人/联系电话」列 |
| 柱镜栏空白 | 填 0.00 |

## 三、第二步：双击「1-处理订单」

1. 确认订单 Excel 已放进 `inbox/`。
2. 双击 **`1-处理订单.command`**，会弹出终端窗口自动运行。
3. 屏幕显示解析/匹配/分流结果，并停在**质检关口**：
   ```
   配货单: output/2026-05-30/labels.xlsx
   确认写入? [Enter=是 / n=否]:
   ```
4. **打开配货单核对**度数、序列号、收货信息——
   - 无误 → 按 **回车**，写入飞书；
   - 有问题 → 输入 **n** 中止，改好 Excel 再来一次。
5. 看到「✅ 处理完成」即成功。处理过的 Excel 已自动移到 `inbox/done/日期/`，**不会重复处理**。

> 🍎 **Mac 第一次打开**：右键点 `1-处理订单.command` →「打开」→ 确认。只需一次，以后正常双击。

---

## 四、第三步：仓库拣货

打开 `output/日期/labels.xlsx`，按**货位**逐行取货：

| 列 | 用途 |
|---|---|
| 货位 | 如 `A-01-3-02`，到对应货架取货 |
| 序列号 | 核对镜片实物编号 |
| 镜片码 | 镜片上的防伪码 |
| 顾客 / 眼别 / SPH / CYL | 核对度数 |
| 代理商 / 收货地址 | 发货目标 |

---

## 五、第四步：双击「2-扣库存」

仓库拣货核对**无误后**：

1. 双击 **`2-扣库存.command`**。
2. 屏幕显示最近批次，问「确认扣减 N 片库存？」→ 按 **回车**。
3. 完成后：飞书库存对应度数减少，该批镜片明细状态转「已发货」。

> ⚠️ 扣减不可自动恢复，**务必仓库核对无误后再点**。
> 扣的是「最近处理的那一批」。要扣更早批次，用命令：`python deduct.py 批次号`。

## 六、命令行方式（备用 / 排障）

```bash
cd 04-供应链/feishu-setup/order-system-v2
source .venv/bin/activate

python main.py ./inbox/             # 处理（带质检关口）
python main.py ./inbox/ --dry-run   # 只解析不连飞书（调试）
python main.py ./inbox/ --no-sync   # 处理出Excel但不写飞书（预览）
python main.py ./inbox/ --skip-qc   # 跳过质检直接写

python deduct.py                    # 扣最近一批
python deduct.py BATCH-xxxx         # 扣指定批次
```

**换库 / 首次建表**：改好 `.env` 后运行 `python setup_tables.py`，自动建「批次汇总」「SKU序列号映射」两张表并灌入 SKU。

## 八、常见问题

**Q：代理商 AG-xxx 不在主表**
文件名编号写错，或该代理商未在飞书代理商表启用。

**Q：SKU 度数不在序列号映射表**
度数超出已登记范围（如 -7.50 / -8.00），或该型号未登记。要支持就往飞书「SKU序列号映射」表加一行（产品型号 / 球镜SPH / 柱镜CYL / 序列号 / 货位），**不用改程序**。

**Q：双击 .command 没反应 / 提示「身份不明的开发者」**
右键点该文件 →「打开」→ 确认（Mac 首次放行，只需一次）。

**Q：飞书写入报 Forbidden（91403）**
应用没加入该 Bitable。打开飞书表 →「···」→「添加文档应用」→ 搜 `cli_a958c5e372b85cb0` → 授权「可编辑」。

**Q：inbox 里旧文件会不会重复处理**
不会。处理成功后自动归档到 `inbox/done/日期/`。
