## 三、Excel 文件规范

### 3.1 文件命名

```
AG-001_20260530.xlsx      ← 标准格式（代理商ID + 日期）
AG001_20260530.xlsx       ← 也支持（无连字符）
```

代理商 ID 从飞书**代理商表**中查取，格式为 `AG-001`～`AG-xxx`。

### 3.2 每眼一行格式（推荐）

| 顾客姓名 | 产品型号 | 眼别 | 球镜SPH | 柱镜CYL | 轴位AXIS | 终端门店 | 备注 |
|---------|---------|------|--------|--------|---------|---------|------|
| 张三 | Ultra双效 | 右眼 | -2.00 | -0.75 | 45 | 北京朝阳店 | |
| 张三 | Ultra双效 | 左眼 | -1.75 | -0.50 | 90 | 北京朝阳店 | |

- **眼别**接受：右眼/左眼/右/左/R/L/OD/OS（不区分大小写）
- **产品型号**须与飞书 SKU 序列号映射表一致，当前支持：`Ultra双效`
- **列名**支持多种别名（如"球镜"="球镜SPH"="SPH"），详见 config.py

### 3.3 每人一行格式（兼容）

## 四、日常操作步骤

### Step 1：放入 Excel

将代理商发来的订单 Excel 复制到 `inbox/` 目录。  
一次可放多个文件（多个代理商），pipeline 会批量处理。

### Step 2：运行 Pipeline

```bash
source .venv/bin/activate
python3 main.py ./inbox/
```

Pipeline 会依次执行：
1. 从飞书加载代理商表、SKU映射、库存
2. 解析所有 Excel，识别代理商+眼别+度数
3. 匹配序列号、货位、镜片码
4. 按库存分流：有货 → 配货单，无货 → 排产单
5. 生成 `output/YYYY-MM-DD/` 下的 Excel 文件
6. 弹出**质检关口**，等待人工确认
7. 确认后写入飞书镜片明细表

**质检关口提示：**
```
  ┌─ 质检关口 ──────────────────────────────────────┐
  │  配货单: output/2026-05-30/labels.xlsx
  │
  │  请打开以上文件核对数据后，按 Enter 继续写入飞书
  │  按 Ctrl+C 或输入 n 中止
  └────────────────────────────────────────────────┘
  确认写入? [Enter=是 / n=否]:
```

打开配货单核对无误后按 **Enter** 继续；发现问题按 **n** 中止，修正 Excel 后重新运行。

### Step 3：仓库拣货

打开 `output/YYYY-MM-DD/labels.xlsx`，配货单按**货位**排序，逐行拣货。

| 列 | 说明 |
|----|------|
| 货位 | 如 `A-01-3-01`，到对应货架取货 |
| 序列号 | 镜片唯一编号，核对实物序列号 |
| 镜片码 | 印在镜片上的防伪码 |
| 代理商 / 终端门店 | 发货目标 |

### Step 4：扣减库存

仓库核对完成、镜片装箱后执行：

```bash
python3 deduct.py BATCH-20260530-113557
```

批次号从 Step 2 的输出日志中复制（格式：`BATCH-YYYYMMDD-HHMMSS`）。

执行后：
- 飞书**度数级成品库存**对应度数库存减少
- 飞书**镜片明细**该批次所有记录状态更新为「已发货」

## 五、命令参数说明

```bash
# 完整流程（默认，有质检关口）
python3 main.py ./inbox/

# 只解析 Excel，不连接飞书（调试用）
python3 main.py ./inbox/ --dry-run

# 完整处理但不写飞书（本地预览用）
python3 main.py ./inbox/ --no-sync

# 跳过质检关口直接写入（自动化/批处理用）
python3 main.py ./inbox/ --skip-qc

# 扣减指定批次库存
python3 deduct.py BATCH-20260530-113557
```

## 八、常见问题

**Q：代理商 `AG-xxx` 不在主表中**  
检查 Excel 文件名是否含有效的 AG 编号，并确认该代理商已在飞书代理商表中启用。

**Q：SKU `Ultra双效` SPH/CYL 不在序列号映射表**  
该度数超出当前 219 个 SKU 范围，无法匹配序列号。查看 `errors.xlsx` 确认具体度数。

**Q：飞书写入报 Forbidden（91403）**  
应用未加入该 Bitable。打开飞书多维表格 → 右上角「···」→「添加文档应用」→ 搜索 `cli_a958c5e372b85cb0`，授权「可编辑」。

**Q：inbox/ 中没有 .xlsx 文件**  
确认文件已复制到 inbox/ 目录，且扩展名为 `.xlsx`（不支持 `.xls`）。

**Q：运行后 inbox/ 的旧文件会被处理**  
每次运行会处理 `inbox/` 下**所有** `.xlsx` 文件。建议每批处理完后将文件移到归档目录，避免重复处理。
