## 五、发现的问题与建议

**P1 · 本地兜底数据代理商号格式不一致**（建议修）
`dry-run`（走本地兜底数据）报「代理商 AG-011 不在主表」——因 `local_master.LOCAL_AGENTS` 的 key 是 `AG011`（无连字符），而文件名识别出 `AG-011`。正式连飞书无此问题（飞书已是 `AG-xxx`）。但**若飞书不可用退回本地兜底，代理商匹配会全失败**。建议把 `LOCAL_AGENTS`/`LOCAL_STORES` 的 code 统一为 `AG-0xx`。

**P2 · 非标订单需人工转换**（流程建议）
代理商实际发来的订单格式五花八门（本单表头错位、无 AG 号、无门店列）。建议二选一：① 下发统一订单模板给代理商填写；② 做一个「非标 → 标准」转换适配层（识别表头行、从单元格提取客户名→代理商、CYL 空白默认 0）。

**P3 · CYL 空白可默认 0.00**（小优化）
纯球镜订单 CYL 常留空，系统当前报「CYL 缺失」需人工补。可在 `intake` 把空 CYL 默认 0.00（仅框架镜/明确无散光场景），减少人工干预。
