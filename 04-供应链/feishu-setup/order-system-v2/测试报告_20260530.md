## 四、已知限制

| 限制项 | 说明 |
|--------|------|
| SKU 范围 | 当前仅支持 Ultra双效 的 219 个度数组合，其他型号或超范围度数自动转排产 |
| 批次汇总表 | 当前测试 Bitable 无独立批次表，批次号仅存在于镜片明细的订单编号字段 |
| 门店地址自动填充 | 当前测试数据门店未在本地主表中，收货地址为空（生产环境需维护门店主数据） |
| inbox 不自动清理 | 每次运行处理 inbox/ 内所有文件，需手动归档已处理文件 |
