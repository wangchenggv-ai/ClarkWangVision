# 财务结算和对账单 - 状态文件

> 更新：2026-05-23

---

## 一、设计原则

- **飞书低代码优先**：能用飞书原生功能实现的不编程
- **避免过早耦合**：财务功能不写入订单系统代码
- **够用就好**：现阶段手工+飞书，规模大了再升级

---

## 二、功能清单与实现方式

| 功能 | 实现方式 | 状态 | 说明 |
|------|----------|------|------|
| 定价表 | 飞书新建表 + 公式字段 | ⏳ 待配置 | 代理商ID + 产品型号 + 单价 |
| 锁价 | 飞书查找字段 + 公式 | ⏳ 待配置 | 订单表查找定价表，锁定单价 |
| 预存款流水 | 飞书新建表 | ⏳ 待配置 | 记录充值/扣款/退货 |
| 余额汇总 | 飞书汇总字段 | ⏳ 待配置 | 从流水表实时计算余额 |
| 下单扣减 | 飞书自动化 | ⏳ 待配置 | 提交订单时自动写扣款流水 |
| 退换货登记 | 飞书新建表 | ⏳ 待配置 | 记录退换货信息 |
| 返利规则 | 飞书新建表 | ⏳ 待配置 | 代理商 + 门槛 + 每件返利 |
| 返利记录 | 飞书新建表 + 公式 | ⏳ 待配置 | 自动计算季度返利金额 |
| 7天自动签收 | 飞书自动化（定时触发） | ⏳ 待配置 | 每天检查发货超7天订单 |
| 对账单 | 飞书筛选视图 + 汇总行 | ⏳ 待配置 | 按代理商+日期筛选，导出Excel |

## 四、飞书配置清单

### 4.1 需要新建的表

| 表名 | 字段 | 说明 |
|------|------|------|
| agent_pricing | 代理商ID、产品型号、单价、拼接key | 定价表 |
| agent_deposit_log | 代理商ID、类型、金额、关联订单号、操作人、时间 | 预存款流水 |
| return_exchange | 日期、原订单号、代理商、产品型号、眼别、类型、原因、责任方、退款金额、处理人 | 退换货登记 |
| rebate_rule | 代理商ID、季度发货量门槛、每件返利金额 | 返利规则 |
| rebate_record | 代理商ID、季度、合计签收量、应得返利金额、状态、抵扣目标季度 | 返利记录 |

### 4.2 需要配置的自动化

| 自动化 | 触发条件 | 动作 |
|--------|----------|------|
| 下单扣减 | 订单表新增记录 | 在预存款流水表写入扣款记录 |
| 7天自动签收 | 每天定时（如凌晨3点） | 查询发货超7天订单，更新状态为已签收 |

### 4.3 需要配置的视图

| 视图 | 筛选条件 | 汇总行 |
|------|----------|--------|
| 对账单视图 | 代理商 + 签收日期范围 | 数量合计、金额合计 |

---

## 五、实施顺序

```
第一步（飞书配置，1-2天）：
  建所有新表 → 配置公式字段 → 配置自动化

第二步（联调，1天）：
  全流程测试：下单→签收→退换货→返利→对账单
```
