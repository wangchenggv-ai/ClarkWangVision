## 三、使用方式

### 3.1 查看通行单

1. 打开飞书多维表格
2. 切换到"已发货-随货通行单"视图
3. 查看"随货通行单内容"列

### 3.2 导出为PDF

**方案1：浏览器打印**
1. 打开视图
2. 浏览器菜单 → 打印
3. 选择"保存为PDF"
4. 调整布局为A4

**方案2：飞书自动化消息**
1. 订单状态更新为"已发货"时自动触发
2. 飞书消息收到通行单内容
3. 复制内容到飞书文档
4. 导出为PDF

**方案3：手动复制**
1. 复制"随货通行单内容"字段内容
2. 粘贴到飞书文档
3. 导出为PDF
