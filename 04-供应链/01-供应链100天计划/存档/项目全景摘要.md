## 六、供应链全景与限速步骤

### 6.1 端到端链路

```
模具(3-8周) → 毛坯(3-4周) → 车房加工(3-5天) → 装配发货(2-5天) → 客户签收
  ↑限速步骤1       ↑限速步骤2         ↑中游瓶颈
```

**最长链路（模具到期→收货）：约60天**
- 模具生产(4周) → 模具验证(3天) → 毛坯生产(3周) → 毛坯验证(3天) → 车房(5天) → 交付(5天)

### 6.2 分层库存策略（推拉结合）

```
🔴 模具：关键产品≥2颗/型，提前4周触发采购
🟠 毛坯：安库=日均×21天×1.2，推式生产不低于2,000片
🟡 成品(高频SKU)：50个SKU覆盖70%订单，推式备库2-3天发货
🟢 成品(低频SKU)：零库存，按单生产，5-7天交付
```

### 6.3 车房分工

| 车房 | 承接产品 | 产能 | 角色 |
|------|---------|------|------|
| **欧陆** | Ultra(批量)、小旋风 | 日处理3,000片(估) | **主力** |
| 九次方 | Ultra(零单) | 4台磨床 | 零单补充 |
| 圣谱 | Ultra(批量)、时空之眼(装配) | 日产60-90副 | 备份+装配 |
| 五彩 | 时空之眼(切割) | — | 专属 |
