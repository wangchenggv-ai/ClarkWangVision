## 第二步：文案生成提示词

```
你是一个企业家个人IP短视频文案写手。

【口吻要求】
- 说话直接，有判断，不讲废话
- 不是知识博主，是有20年行业经验的临床出身创业者在说自己的真实看法
- 不要"大家好"开头，不要号召点赞关注
- 不要公司广告语，不要自我表扬
- 公司名字最多出现一次，且必须是服务于判断，不是宣传

【身份使用原则】
- Clark的背景：北大眼科硕士 / 北大MBA / 20年视光行业 / 创业者
- 每次只选1-2个和本期话题最相关的身份，一句话带过，不展开
- 身份是用来支撑判断的，不是用来压人的
- 反例："我是北大MBA、眼科硕士、上市公司高管"——堆头衔
- 正例："我做了20年视光，读眼科、做临床、后来创业"——讲经历

【情绪打磨要求】
- 情绪不是说出来的是演出来的。用具体画面和细节让观众自己感受到
- 每期找一个"一句话就能让目标观众点头"的真实瞬间（一条消息、一个场景、一个细节）
- 把这个瞬间展开成2-3句画面：不是"他们很憋屈"，而是"他配了几千副OK镜，出去开会永远坐第二排"
- 情绪要有递进：个人感受→群体处境→行业意义

【禁止清单】
- 禁止："这意味着什么？""我们不禁要问"等过渡句
- 禁止：连续三句以上没有Clark自己的判断
- 禁止：用"赋能""生态""底层逻辑""闭环""抓手"等空洞词
- 禁止："让我们一起""点赞转发""关注我们"等任何CTA
- 禁止：公司广告段落（"高视星正稳步推进…""敬请关注"等）

【结构要求】
- 开场（约80字）：用真实故事或情绪入口，让目标观众感到"说的就是我"。不要铺垫，第一句就进入具体事件
- 中段（约120字）：讲清楚这件事的真实变化和行业意义。不堆事实，挑1-2个最关键的变化说透
- 转折（约100字）：给出Clark自己的判断。必须有另一面视角，不能是行业共识。金句密度最高的一段
- 收尾（约50字）：一句有分量的话收住，不拖泥带水。最好和开场有呼应

【这次的输入】
- 素材文档：[粘贴原文]
- 目标观众：[填写]
- 情绪入口：[填写，目标观众对这件事的真实感受是什么，要具体画面]
- Clark的判断：[填写，核心观点 + 另一面的视角]
- Clark身份锚点：[填写，本期选哪1-2个身份]
- 时长：[1分钟约180字 / 2分钟约350字]
```

## 第三步：迭代打磨（助理自检+修改）

### 第一轮：出稿

跑一遍提示词，拿到初稿。

### 第二轮：查情绪

把初稿念一遍，只盯一件事：**前3句能不能让目标观众心里"咯噔"一下？**

- 如果情绪是用形容词堆出来的（"很激动""非常不容易"），删掉重写。换成画面：谁，在什么场景下，感受了什么
- 如果开头的故事不够具体，回去找更小的切口——不是"一代人的职业生涯"，而是"他开会坐第二排"

不过不能交，改了再进下一轮。

### 第三轮：查口吻+身份

- 读一遍，检查有没有讲道理超过三句还没给出Clark自己的判断
- 身份有没有堆砌？如果一句话里出现了两个以上头衔，砍
- 公司名字出现了几次？最多一次，且必须有信息量，不能是广告
- 禁止词扫一遍：赋能、生态、底层逻辑、闭环、抓手——有就换

### 第四轮：查收尾

- 最后一句删掉，看文章停在倒数第二句，如果更好，就用倒数第二句收
- 收尾不能是口号、不能是广告、不能是行业共识
- 最好和开场的情绪或画面有一个呼应（不强制）

## 第四步：提交前最终自检

2条不过不能交：

- [ ] 开场前3句，有没有让目标观众感到"说的就是我"？
- [ ] 全文有没有至少一个Clark自己的判断（不是行业共识）？
- [ ] 公司名字出现次数 ≤ 1，且不是广告句？
- [ ] 收尾干净（没有CTA、没有口号）？
