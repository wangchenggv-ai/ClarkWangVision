## 1. 核心概念速览（讲解重点）

- **OpenClaw（业内昵称“龙虾”）为什么突然火**  
  2025年底开源的本地 AI Agent 框架，2026年初迅速爆火。它让 AI 从“只会聊天”真正变成“能做事”的工具：通过微信或企业微信直接操控电脑（浏览器、文件、PowerPoint 等），支持本地运行，隐私安全、无需联网。腾讯将其简化成 WorkBuddy，进一步降低了企业使用门槛。这标志着 AI 从“辅助工具”走向“办公同事”。

- **Agent 与 聊天机器人（豆包、Coze 基础 bot）的本质区别**  
  聊天机器人擅长单轮或多轮对话，输出文字、图片、建议，但记忆短暂，每次像新对话。  
  Agent（智能体）是目标导向的自主系统，能够自主规划、调用工具、多次迭代，直至完成复杂任务。  
  简单总结：聊天机器人“会说”，Agent“会做”。

- **Soul.MD**  
  Agent 的“灵魂配置文件”，采用 Markdown 格式编写。它定义了 Agent 的人格设定、价值观、语气风格、行为准则以及品牌规范（如“必须使用公司 VI 色系”）。每次任务自动注入上下文，确保输出稳定、一致、专业。

- **Agent 记忆（Memory）**  
  传统大模型每次对话均为“失忆”状态。Agent 的持久记忆功能可记住用户长期偏好、项目历史、领导反馈、设计风格等，实现跨任务连续迭代，大幅减少重复沟通。

- **Skill（技能）**  
  Agent 的“双手”，指可调用的具体能力模块（如读取 Excel、生成图表、操控 PowerPoint、浏览器自动化等）。OpenClaw 和 WorkBuddy 均内置丰富 Skill 库，支持一键扩展。

- **Markdown 文档**  
  轻量级标记语言，用于结构化文本（标题、列表、表格、代码块等）。它是 Agent 配置、知识库、提示模板和输出的标准格式，AI 高度兼容，便于版本管理和跨平台使用。

## 2. PPT 三步法（我的实战经验）

高质量 PPT 绝不是“三步同时进行”，而是**一次只专注一步**，才能保证逻辑严密、视觉专业。

1. **Step 1：框架与大纲**  
   核心任务：想清楚这个 PPT 到底要表达什么？  
   - 明确核心观点、目标受众、关键信息。  
   - 输出结构化大纲（标题、章节、每页要点）。  
   AI 优势：Agent 可根据主题快速生成逻辑清晰的大纲，并确认是否符合预期。

2. **Step 2：资料搜索与汇总**  
   核心任务：把零散信息整理成严密结构。  
   - 读取 Excel 等数据、自动清洗、计算关键指标、生成图表。  
   - 补充专业资料、案例，进一步梳理故事线。  
   AI 优势：Coze 可直接调用 Read Excel 和图表大师插件，分钟级完成数据处理。

3. **Step 3：专业美化**  
   核心任务：突出核心观点，让观众一眼 get 到信息。  
   - 配色方案、排版逻辑、图表优化、动画提示。  
   - 统一品牌 VI 风格。  
   AI 优势：WorkBuddy 本地执行，直接在 PowerPoint 中渲染并应用模板。

**AI 时代核心优势**：三步全部可交给 Agent 完成，效率提升数倍，同时避免人为疏漏。

## 3. 工具准备与使用流程（推荐混合使用方案）

- **Coze（扣子）**：云端“大脑”  
  负责 Step 1 和 Step 2：框架生成、数据分析、内容创作。支持工作流和插件，可直接生成结构化 Markdown。

- **WorkBuddy（腾讯）**：本地“双手”  
  负责 Step 3：直接操控电脑上的 PowerPoint，应用公司 VI 模板、插入图表、统一排版、添加动画，最终生成真实 .pptx 文件。

**为什么 Coze 云端生成 PPTX 后仍需切换 WorkBuddy？**  
- Coze 擅长快速生成内容，但输出的是静态文件，需手动下载和二次调整。  
- WorkBuddy 完全本地运行，数据不出电脑，符合企业隐私合规；可直接调用本地 PowerPoint API，实现零缝隙适配公司模板、字体、宏命令，效率更高、专业度更强。  
- 混合使用才是最佳实践：Coze 完成内容生成 → WorkBuddy 完成本地渲染。
