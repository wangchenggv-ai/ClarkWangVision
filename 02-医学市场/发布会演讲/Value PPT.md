##  Vision：近视防控进入数据驱动时代-家长为效果付费

### 要点

- **行业趋势**：政策端要求可量化的防控效果，家长端要求可验证的临床结果
- **行业现状**：终端机构普遍缺乏系统化的临床数据采集与分析能力
- **高视星判断**：临床数据将成为视光终端的核心竞争力

##  Alliance + Expert：CDSA架构与三方分工

### 要点

- **CDSA定义**：基于统一数据标准与AI技术的临床协作网络/Clinical Data Strategic Alliance
- **首席科学家：临床科学标准制定与学术监督
- **咏柳科技**：软件平台
- **高视星**：数据采集协议制定、产品闭环、AI能力支撑


## User + Location：联盟成员权益

### 三层收益

**第一层：工具赋能**
- 病程管理系统部署至终端机构
- 覆盖患者建档、随访管理、数据可视化及AI辅助临床决策
- 直接提升复购率和患者留存

**第二层：数据反哺**
- 联盟数据用于AI模型训练
- 成员优先获得临床决策支持工具
- 数据规模越大，模型越精准，每个成员都受益

**第三层：品牌赋能**
- 联盟成员认证体系，同仁品牌授权
- 提升终端专业形象与患者信任度
- 构建差异化竞争壁垒
