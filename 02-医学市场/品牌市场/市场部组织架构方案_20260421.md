# 高视星市场部组织架构方案

**日期**:2026年4月21日
**背景**:基于4月20日1on1纪要的批判性重构
**核心逻辑**:把市场总监从执行者解放到架构师+外交官位置

---

## 一、核心判断

### 1.1 业务本质的再定位

高视星是**医疗器械公司。市场部的命脉是**学术权威+终端关系**,不是内容生产。

### 1.2 市场总监的稀缺价值

市场总监(眼科硕士背景,医学+市场双栖)的**不可替代性**在于:

- 眼科医学底子 → KOL对话、临床证据解读、CDSA学术背书
- 战略判断 → 市场节奏、竞品应对、资源分配
- 跨部门协调 → 与CEO、销售、研发、CDSA客户之间的黏合剂

**她不该做的**:
- 写稿、排版、剪视频、发公众号
- 盯活动执行细节、订场地、对接物料
- 做基础数据报表、整理会议材料
- 一线客户的日常跟进

## 二、市场部组织架构建议

### 2.1 最终团队形态

```
          市场总监 (CEO的核心副驾)
               │
    ┌──────────┼──────────┐
    ↓          ↓          ↓
  学术助理   活动经理   数字专员
  (医学执行) (会议执行) (AI内容)
               │
          外部顾问 (虚线,项目制)
```

**编制:3人核心 + 1个外部顾问 + 市场总监,共4人编制**

### 2.2 角色配置详解

#### 角色1:学术助理/医学事务专员

| 项目 | 内容 |
|---|---|
| **画像** | 眼视光本科或硕士,能看懂论文、会写学术材料,有1-2年医院或器械公司经验 |
| **核心职责** | 承接市场总监的学术输出:整理CDSA数据、写学术PPT、做文献综述、准备会议发言稿;对接KOL日常;OK镜/抗疲劳OK镜上市的技术材料产出 |
| **为什么关键** | 把"学术+市场"两头跑的压力接走,市场总监只做终审和对外输出 |
| **招聘优先级** | 高(CDSA推进刚需) |

#### 角色2:会议与活动经理

| 项目 | 内容 |
|---|---|
| **画像** | 执行力强、细节控、会用飞书/项目管理工具 |
| **核心职责** | 所有推广会、学术会、CDSA客户会的全流程执行;预算控制、供应商管理、物料、场地;活动后的数据复盘 |
| **为什么关键** | 让市场总监只出现在"决定活动方向"和"关键客户接待"两个环节 |
| **招聘优先级** | 中(可从现有团队优化) |

#### 角色3:数字内容与增长专员(AI-native)

| 项目 | 内容 |
|---|---|
| **画像** | 25-32岁,熟练使用剪映+AI视频+Coze+GLM+Midjourney类工具,懂内容传播规律 |
| **核心职责** | 百家探店视频生产(AI辅助批量化);家长教育内容矩阵(小红书/抖音/视频号);投放数据分析+内容迭代;为CDSA和OK镜上市提供内容弹药 |
| **为什么关键** | 这是市场总监当下完全没有的能力杠杆,不是替代她,是给她加一个新维度 |
| **招聘优先级** | 最高(OK镜上市前必须到位) |

#### 角色4:外部品牌/数字化顾问(项目制)

| 项目 | 内容 |
|---|---|
| **画像** | 头部医疗/消费品牌的前市场人,按项目付费 |
| **形式** | 每月1-2次深度咨询,不入编 |
| **核心价值** | 给市场总监提供外部视角和前瞻方向;OK镜上市节奏、品牌定位、高端市场打法;避免团队自我说服 |
| **为什么关键** | 市场总监最大的风险不是能力不够,而是缺乏外部锚点。顾问比招一个副手更轻、更高杠杆 |

## 三、AI时代的前瞻性设计

这个方案和传统市场部最大的不同:

| 传统市场部需要 | AI时代配置 |
|---|---|
| 4-5个内容生产者 | 1个AI-native数字专员 |
| 专门的数据分析师 | Coze/GLM+飞书多维表格,市场总监直接问数据 |
| 庞大的活动执行团队 | 1个活动经理+外包供应商 |
| 外部品牌公司长期合约 | 顾问制,按需付费 |

**但AI替代不了的岗位仍然需要人**:
- 医学权威性 → 学术助理辅助,市场总监终审
- KOL关系 → 市场总监亲自维护
- 战略判断 → 市场总监+外部顾问
- 会议现场的人和人 → 活动经理

---

## 四、与客户成功(CS)岗位的关系

### 4.1 CS不归市场部,但暂时挂靠CEO

- **方向**:CS独立设置,避免与市场部获客KPI冲突
- **归属**:初期直接向CEO汇报,跑通流程后再下放给产品/运营总监
- **招聘**:外部引进,不内部转岗(培训师留原岗继续做技术赋能)

### 4.2 市场部与CS的协作流程

```
市场部
  ↓ 发现种子客户 → 初步联系 → 建立关系
  ↓ 交接
客户成功经理(独立)
  ↓ 深度跟进 → 解决问题 → 协助培训
  ↓ 裂变激励
  ↓ 反馈 → 产品改进
```

## 六、KPI设计(避免虚荣指标)

### 6.1 市场部整体KPI

**不用的指标**(虚荣指标):
- ❌ 推广会参会人数
- ❌ 视频播放量绝对值
- ❌ 公众号阅读量

**建议的指标**(业务结果导向):
- ✅ **种子终端月均验配量**(北极星指标)
- ✅ **CDSA数据合格入组率**
- ✅ **OK镜上市后3个月激活终端数**
- ✅ **高质量KOL合作数**(发表SCI或参与CDSA的医生数)

### 6.2 各岗位KPI要点

| 岗位 | 核心KPI |
|---|---|
| 学术助理 | 学术材料产出量+质量;KOL互动频次 |
| 活动经理 | 活动按期完成率;预算控制;参会客户后续转化率 |
| 数字内容专员 | 内容产出量;**种子终端通过内容转化率**(不是播放量) |

## 七、风险提示

### 7.1 组织风险

:"放手"后CEO的时间承接问题**

- 市场总监解放出来做高价值工作,CEO也要解放她去承接一部分对外工作
- 否则解放的价值没兑现

### 7.2 招聘风险

**风险1:数字内容专员招聘坑**

- 简历上写"AI熟练"的人90%不合格
- **应对**:笔试+现场用Coze做一个短视频脚本,真刀真枪验证

**风险2:学术助理稀缺**

- 既懂眼视光专业又能写学术材料的复合型人才不多
- **应对**:可以考虑应届眼视光硕士,由市场总监亲自带教
