## 技术栈

- 单文件 HTML，零依赖，无构建步骤
- 字体：Noto Serif SC + Noto Sans SC（Google Fonts CDN）
- 深色主题，海军蓝底 + 金色点缀
- CSS 动画：浮动光球、几何线条、滚动渐入（IntersectionObserver）
- 倒计时组件（JS）
- Tab 切换日程（Day 0 / Day 1 / Day 2）

## 页面结构

```
Hero 区
  ├── 倒计时（目标日期 2026-06-10T09:00:00+08:00）
  ├── 会议名称 badge
  ├── 主标题 + 副标题
  └── 日期 / 地点 / 公司信息
```

## 更新内容流程

### 1. 修改议程 / 文案

直接编辑本地 HTML 文件，修改对应的 HTML 文本即可。关键区域：

- **Hero 区文案**：搜索 `hero-badge`、`hero-title`、`hero-subtitle`
- **日程内容**：搜索 `panel-0`、`panel-1`、`panel-2`，修改 `tl-time`、`tl-title`、`tl-desc`
- **会议地点**：搜索 `venue-card`
- **倒计时日期**：搜索 `new Date('2026-06-10T09:00:00+08:00')`

## 样式自定义速查

| 元素 | CSS 类 | 说明 |
|------|--------|------|
| 顶部导航 | `nav` | 固定顶部，滚动变深 |
| 会议名称 | `hero-badge` | 金色圆角标签，font-size: 20px |
| 主标题 | `hero-title` | Noto Serif SC，clamp(32px, 6vw, 64px) |
| 日程时间线 | `timeline` / `tl-item` | 左侧金色竖线 + 圆点 |
| 高亮环节 | `tl-item.highlight` | 圆点填充金色 + 光晕 |
| 标签 | `tl-tag.core` / `.gala` / `.optional` | 不同颜色标签 |
| 卡片 | `venue-card` | 毛玻璃效果，hover 上浮 |
