## 一、战略背景

### 市场环境
- 儿童OK镜市场：政府强力限价干预，30家企业竞争，红海格局
- 公司儿童OK镜产品线6月退出竞争性扩张，转为守势
- 成人OK镜市场几乎空白，品类尚未被定义

### 核心战略判断
**不是退出儿童市场，而是用成人市场带动儿童市场。**

```
成人OK镜（高端/生活方式）
        ↓ 品牌溢价传导
儿童OK镜（同品牌背书，抵抗价格战）
```

类比逻辑：Lululemon用女性瑜伽线建立品牌调性，男性线借势成功。  
**品牌是唯一不能被限价的资产。成人线是构建这个资产的工具。**

## 三、成人OK镜产品定位

### 核心差异化
**同时矫正近视与早期老视，白天完全裸眼，远近皆清晰。**  
这是市场上几乎没有竞争对手的真实差异化。

### 目标人群（三类）

| 人群 | 核心痛点 | 转化逻辑 |
|------|---------|---------|
| 近视框架镜用户（38-50岁） | 近视+早老花，两副眼镜噩梦 | 一片镜片全解决 |
| 隐形眼镜用户 | 没有老花隐形可选，被迫换框架镜 | 夜戴OK镜，白天裸眼自由 |
| 抗拒手术用户 | 不想做激光，但想裸眼 | 可逆的非手术方案 |

### 品牌定位
- **品牌名（暂定）：裸眼自由**
- **核心方向：抗疲劳 + 裸眼自由**
- **关键原则：不出现"老花"二字**

### 三层传播语言

| 层次 | 核心语言 | 对象 |
|------|---------|------|
| 消费者语言 | 裸眼自由 / 不再累 / 睡一觉换来一整天清晰 | 早老花目标人群 |
| 医生语言 | 早期老视的非手术干预方案，近视合并老视同时矫正 | 眼科/视光医生 |
| 品牌语言 | 成人视觉自由解决方案，轻医疗生活方式品牌 | 市场/投资人 |

## 四、两轨推广策略

### 公立KOL vs 私立种子用户

| | 公立KOL | 私立种子用户 |
|--|---------|------------|
| 目标 | 树立品类概念，建立学术信任 | 验配出量，积累真实案例 |
| 角色 | 背书者 | 执行者 |
| 产出 | 学术演讲/文章/会议发言 | 患者数据/用户故事/销售额 |
| 激励方式 | 学术合作/课题/署名 | 商业政策/数据支持/优先供货 |
| 沟通语言 | 临床价值/循证数据 | 市场机会/商业回报 |

**核心原则：公立KOL不能用来出量，私立种子不能用来树概念。角色混淆两边都会出问题。**

### 执行节奏
```
现在-6月：公立KOL以学术交流切入，不谈商业，提前给临床数据和材料
7月上市：私立种子中心同步启动验配出量
下半年：公立KOL开始在会议/平台发声，为私立背书
```

## 七、数据收集体系

### 收集什么

| 数据类型 | 具体指标 | 用途 |
|---------|---------|------|
| 临床效果 | 近视度数变化、老花改善幅度 | 学术背书 |
| 用户体验 | 适应期长短、舒适度评分 | 消费者内容 |
| 依从性 | 实际夜戴频率、停戴率 | 医生说服 |
| 满意度 | NPS评分、复购意愿 | 商业验证 |

### 数据三种用法
```
临床数据 → 发表文章/学术会议 → 医生端信任
用户故事 → 小红书/抖音真实案例 → 消费者种草
汇总报告 → 投资人/合作方 → 商业背书
```
