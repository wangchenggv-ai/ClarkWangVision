# 中央看近型（CN）设计 OK 镜研发测试报告

## 一、测试目标

1. 验证 CN 设计镜片相比普通 OK 镜，看近是否有改善
2. 每次只调整一个参数，对比看远 / 看近表现差异

## 二、测试对象

| 眼别 | 度数区间 | 等效球镜 | 主导眼 |
|:---:|:---:|:---:|:---:|
| 右眼 | 低度近视 | ≈ -2.00D | 是 |
| 左眼 | 高度近视 | ≈ -5.50D | 否 |

双眼参数独立调整，形成两条并行迭代线：**右眼 = 低度近视组**，**左眼 = 高度近视组**，各 5 轮迭代。

## 三、测试方法

以之前看远设计参数为基线，生产 CN 设计镜片，每次只调整一个参数（C factor / ADD / 度数），观察片上看远、片上看近、摘镜看远、摘镜看近四个维度的变化。

## 四、右眼迭代线（低度近视 ≈ -2.00D）

| 轮次 | BC | 度数 | 直径 | ADD | C factor | 调整项 | 片上看远 | 片上看近 | 摘镜看远 | 摘镜看近 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|------|

| R2 | 44.25 | -1.25 | 10.6 | +1.5D | **6.0** | C↑ | 没影响 | — | 比之前好（之前 MCOK 有过矫） | C↑ 对看远无负面影响，看近跟 R1 比没有太大变化 |
| R3 | 44.25 | -1.25 | 10.6 | **+2.5D** | 6.0 | ADD↑ | 清晰 | 保持 | 0.8（隔天佩戴） | ADD↑ 看近改善（隔天佩戴） |

### 右眼小结

- C factor 4.0↔6.0 来回切换，看远看近差异不大 → **低度近视对 C factor 不敏感？**
- C factor 降到极端 1.0，看近明显变差 → **存在下限**
- ADD +1.5D→+2.5D，隔天佩戴看近有改善，可在正常距离看近，但没有 +2.5D 老花镜的效果
- 整体上未达到极好的看近效果，比普通 OK 镜略好，但未达预期

| L2 | 44.00 | **-6.00** | 10.6 | +2.5D | 4.0 | 度数↑↑ | 模糊（小圈干扰） | 不好 | 1.2 | 看近似乎有多焦点感觉 |
| L3 | 44.00 | **-5.25** | 10.6 | +2.5D | 4.0 | 度数↓ | 清晰 | 不好 | 0.8（戴 2 天） | 降度后远清晰但看近一般 |

### 左眼小结

- 度数路径：-4.75 → -6.00（过矫，回调）→ -5.25（找到平衡点）
- C factor 路径：4.0 → 6.0（改善）→ 10.0（恶化）→ **高度近视对 C factor 敏感，存在最优值 6.0？**

## 六、综合对比

| 维度 | 低度近视（右眼） | 高度近视（左眼） |
|------|------|------|
| C factor 敏感度 | 低 — 4.0↔6.0 差异不大，极端 1.0 才变差 | 高 — 4.0→6.0 改善，6.0→10.0 恶化 |
| C factor 最优值 | ≥4.0 即可，不必过高 | 6.0 左右 |
| ADD 影响 | 核心变量，+2.5D 改善看近 | 未单独测试（一直 +2.5D） |
| 度数调节 | 未调整（-1.25 稳定） | 需精细调节，窗口窄 |

---

## 七、综合结论（AI结论）

1. **ADD 是看近的核心变量**，对低度近视效果显著（R2→R3）
2. **C factor 的影响因度数而异**：低度近视不敏感（4.0~6.0 无差异），高度近视敏感（6.0 最优，10.0 反向恶化）
3. **C factor 影响镜片外观**：越大中央圈越明显（1.0 几乎看不见 → 10.0 非常明显）
4. **高度近视调参窗口更窄**：度数过矫（-6.00）和 C factor 过高（10.0）都需要回调
