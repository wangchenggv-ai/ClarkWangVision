> 版本：2026-04-29
> 适用产品线：抗疲劳款 OK 镜（已发布） + 新款老花 OK 镜（2027 发布）
> 战略平台：CN-Design Platform
> 拟用品牌：Second Sight / 再视（商标查询 pending）
>
> 基于 Clark + Claude 2026-04-29 战略对齐讨论形成

## 一、战略坐标

### 一句话使命

**用一个 CN-Design 平台，覆盖 38-55 岁成人视觉全龄段，做全球首个由中国医生设计的 Presbyopia Ortho-K 体系。**

### 战略哲学

- **慢线撑高度，快线跑速度**——临床/学术 2-3 年慢慢做，市场/AI/品牌 12 个月快速推。
- **全球领先要巧劲不要快**——用 dreamlite 创始人 lineage + 适应症扩展 + 平台叙事，避开"全球同步上市"的高风险打法。
- **每年 COOC 都有新东西**——把中国眼科最大年会做成产品发布的年度节拍器。

### 三年路线图（COOC 节拍）

```
COOC 2026 (4月已发布)  │ 抗疲劳款概念首发，启动 RWE 采集
                       │
COOC 2027 (合龙时刻)   │ ① 抗疲劳款 12 个月 RWE 数据
                       │ ② 适应症扩展申请/获批
                       │ ③ 新款老花 OK 镜 SKU 发布
                       │ ④ AI 验配 E2E 现场演示
                       │ ⑤ dreamlite 创始人现场站台
                       │ → 国际化第一年起点
                       │
COOC 2028             │ 老花款 RWE + 国际化推进 + 第二代平台预告
```

## 二、产品线架构

### 双产品代际叙事

|  | 抗疲劳款（现款） | 新款老花 OK 镜（2027） |
|---|---|---|
| 目标年龄 | 38-50 早老花 | 45-55 中度老花 |
| ADD | < 1.0 D | 1.0 - 2.0 D |
| 临床定位 | 提前介入 / 抗疲劳 | 中度老花的非手术答案 |
| 注册路径 | 已在路上 | **适应症扩展**（同一注册证，非新注册） |
| 上市时间 | 2026 已发布 | 2027 COOC 4月 |
| 故事 | 提前一步告别视疲劳 | 跨过 50 岁仍能裸眼自由 |

### 平台战略意义

- 一次研发投入 → 多个适应症变现 → 护城河复利累积
- "成人视觉全龄段平台"是医疗器械经典做大路径（Cooper / 博士伦 / 强生范式）
- 对外叙事一句话：**"中国医生设计的全球首个成人视觉全龄段 OK 镜平台——38 岁到 55 岁，一个 CN-Design 平台两个 SKU。"**

### 适应症扩展 = 隐藏杠杆

| | 走新注册 | 走适应症扩展 |
|---|---|---|
| 时间 | 18-24 个月 | 6-9 个月 |
| 成本 | 数百万 | 数十万 |
| 临床 | 重新试验 | 抗疲劳款 RWE 数据直接支撑 |
| 故事 | "新产品风险" | "经验证平台的自然延展" |

**关键操作**：抗疲劳款 2026 全年 RWE 采集，必须从 day 1 按"支撑扩展申请"标准设计——颗粒度、45-55 岁子集分层、近视力客观指标全部要补齐。**这是今年所有动作中最不可逆的前置工作**。

## 五、关键资产清单

### 1. dreamlite 创始人 lineage（最大资产，最被低估）

**关系现状**：已是 Clark 顾问，已书面认证 Clark 设计能力。

**单点战略**（不发散选海外 KOL）：

| 维度 | 玩法 |
|---|---|
| 故事定位 | "OK 镜鼻祖 → 中国弟子 → 全球首款"师承 lineage |
| 物料化 | 认证证书 + 师徒合影/视频 + 联合 quote 卡片（双语） |
| 学术 | 第一篇论文共同通讯作者 |
| 仪式化 | 每年至少 1 次线下深谈、1 次联合内容、1 次正式署名 |
| COOC 2027 | 主旨嘉宾，老花款发布的"第二个名字" |
| 海外圈层 | 让他**定向引荐** 1-2 位欧洲圈层人物，不发散外溢 |

**唯一要补的**：把"已经是顾问"从被动状态升级为主动仪式化关系。

### 2. 20 共建成人 OK 镜中心

**三重角色**（一份 MOU 一次绑定）：

```
临床观察者（论文署名权）
+ 出量合作伙伴（商业政策 + 5% 季度种子返点）
+ 患者大使来源（每季度推荐 ≥ 2 位故事感强候选）
```

**目标分布**：6 一线 + 8 强二线 + 6 区域中心 = 20 家。公立 / 私立 = 3 KOL + 17 验配主力。

**进度**：销售已开始挖掘候选名单，签约 SOP 待重做。

### 3. 20 患者大使（递进关系）

```
2026 Q3   20 中心入组首批患者
2026 Q4   医生在患者池中物色"故事感强"候选 → 平台筛选签约
2027 Q1   20 大使 × 20 中心联合内容启动（一中心一大使）
2027 Q2   COOC 2027 同步发布"20 个故事 / 20 个城市"
```

**人才来源**：必须由医生发现并推荐，不是品牌外聘网红。这是**"先医生后患者"的递进逻辑**。

### 4. AI 验配 E2E（产品级优先级，不是营销工具）

**重要判断**：AI 验配是 2027 老花款上市的**前置条件**，不是 2026 抗疲劳款的获客工具。

理由：
- 抗疲劳款 ADD < 1D：调参窗口宽，普适性强 → AI 是加分项
- 老花款 ADD 1-2D：调参窗口陡变窄，45-55 岁人群差异巨大 → **没有 AI，1-2D 精准调谐人工做不了**

**E2E 产品形态（待 5.1 后细化）**：
- C 端：处方 + 自拍 + 用眼场景 → "5 分钟可行性报告" → 自动匹配最近共建中心
- B 端：医生看板 → AI 推荐设计参数初稿 → 医生 confirm → 数据自动回流
- 数据层：每一次验配 = 平台变得更准 → 真正的护城河

**进度**：Clark 已起头写代码，5.1 节后产品形态定案。

### 5. Clark 创始人 IP（双语化）

**核心人设**：**"我是设计这副镜片的医生"**

不可替代性：北大眼科硕士 + MBA + dreamlite 师承 + 自己设计镜片——临床/研发/商业三合一。

**升级方向**：
- 中文：视频号 15 条精品（4-6 月）+ 持续运营
- 英文（新增）：LinkedIn 长文 + Substack/X 双语布局
- 目的：给海外医生 KOL、学术圈、未来融资/IPO 提供弹药

## 八、国际化战略：荷兰人单点

**判断**：2027 是国际化第一年，但不急、不撒网、不发散选海外 KOL。

**单点逻辑**：
- dreamlite 创始人本身就是国际权威 → 他做主旨嘉宾即完成 50% 全球可见度
- 让他**定向引荐**他自己圈层的 1-2 位欧洲核心人物 → 不外溢、不增加管理复杂度
- 关系链可控、深度可挖、叙事聚焦

**不做的事**：
- 不主动联系 Patrick Caroline / Helen Swarbrick / 其他 OK 镜国际权威
- 不参加美国 AAOMC、英国 BCLA 等地的展会站台
- 不做海外销售铺货（海外市场不急）

**做的事**：
- 2026 年内 Clark 自费/出差去欧洲拜访 dreamlite 创始人 1-2 次（圈层关系不能远程建）
- 2026 Q4 让他列 1-2 位他愿意引荐的欧洲核心 KOL
- 2026 底前 Clark 与这 1-2 位完成线上首次接触
- 2027 COOC 4月这 1-2 位飞来参会
