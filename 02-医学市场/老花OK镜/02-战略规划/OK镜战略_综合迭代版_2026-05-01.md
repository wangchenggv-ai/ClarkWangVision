## 二、战略坐标（当前最优判断）

### 一句话使命

**用一个 CN-Design 平台，覆盖 38-55 岁成人视觉全龄段，做全球首个由中国医生设计的 Presbyopia Ortho-K 体系。**

### 战略哲学

- **慢线撑高度，快线跑速度** — 临床/学术2-3年慢慢做，市场/AI/品牌12个月快速推
- **全球领先要巧劲不要快** — dreamlite lineage + 适应症扩展 + 平台叙事，避开全球同步上市的高风险打法
- **每年COOC都有新东西** — 把中国眼科最大年会做成产品发布的年度节拍器

### 最底层逻辑

```
成人OK镜高端定位（品牌势能）
        ↓ 反哺
儿童OK镜（同品牌背书，抵抗价格战）
        ↓ 飞轮
CDSA临床数据积累
        ↓
2027老视OK镜适应症扩展正式推出
        ↓
投资人/合作方商业背书增强
```

类比：Lululemon用女性瑜伽线建立品牌调性，男性线借势成功。**品牌是唯一不能被限价的资产，成人线是构建这个资产的工具。**

### 动作5：AI验配E2E（产品级优先级）

> **重要判断**：AI验配是2027老花款上市的**前置条件**，不是2026抗疲劳款的获客工具。

- 抗疲劳款 ADD < 1D：调参窗口宽，普适性强 → AI是加分项
- 老花款 ADD 1-2D：调参窗口陡变窄，45-55岁人群差异巨大 → **没有AI，1-2D精准调谐人工做不了**

产品形态（5.1后细化）：
- C端：处方 + 自拍 + 用眼场景 → "5分钟可行性报告" → 自动匹配最近共建中心
- B端：医生看板 → AI推荐设计参数初稿 → 医生confirm → 数据自动回流
- 数据层：每一次验配 = 平台变得更准 → 真正的护城河
